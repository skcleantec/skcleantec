# 청소 텔레마케팅 상담 원칙 (v1 · 261120)

상담사가 통화 중에 바로 말할 수 있는 문장을 만들고, 통화를 평가하고, 대응 카드를 키울 때 따르는 기준입니다.
우리 자료가 일반 영업 기법보다 우선합니다.

## 0. 먼저 볼 자료 (우선순위)
1. `09_대표님확인.md` — 정해진 기본값. **이것과 다르게 말하지 않는다.**
2. `08_견적기준.md` — 금액·규정의 기준. 금액은 여기 숫자만 쓴다.
3. `10_대응카드_v*.md` — 검증된 대응. 「★」(예약 성사에 쓰인 대응)을 먼저 쓴다.
4. `_원자료/01~05` — 고객 유형·변수·롤플레잉·용어·C/S.
5. 일반 영업 기법(아래 2장) — 우리 자료에 답이 없을 때만.

## 1. 대응 문장을 만들 때의 순서
고객의 말 하나에 아래 순서로 **짧게** 답한다. 다섯 단계를 다 말하지 않아도 된다.

1. **받아 주기** — 「맞아요, 그렇게 보이실 수 있어요.」 (반박부터 하지 않는다)
2. **속마음 확인** — 필요하면 질문 하나. 「혹시 금액이 걸리세요, 아니면 어디가 나은지 고르기가 어려우세요?」
3. **기준 주기** — 고객이 판단할 수 있는 기준 **한 개**. 예: 「예약금이 2만 원 넘는 곳은 중간 수수료가 붙는 경우가 많아요.」
4. **근거 한 줄** — 우리 서비스에 들어간 것(7가지 서비스, 기간 없는 A/S, 직영) 중 하나.
5. **다음 단계** — 예약·안내서·**다시 걸 시각** 중 하나로 끝낸다. 시각은 상담사가 정한다.

## 2. 반론 6갈래와 우리식 대응
| 갈래 | 고객 말 예 | 우리 기본 대응 | 카드 |
|---|---|---|---|
| 가격 | 「비싸요」「8평인데 센데요」 | 구조 기준 한 문장 + 들어간 것 한 줄 + 페이백 적용 금액 | C009·C010·C011·C013 |
| 비교·경쟁 | 「견적 많이 받았어요」「13만 원부터던데」 | 고를 기준(예약금) 하나 | C007·C008 |
| 신뢰 | 「직영이에요?」「전에 별로였어요」「외국인 와요?」 | 선 긋기 + 솔직 화법 + 한계 먼저 | C019·C020·C021 |
| 시기 | 「날짜 미정」「생각해 볼게요」 | 이틀 전까지 변경·취소 자유 → 팀 먼저 잡기 | C028·C038 |
| 결정권 | 「남편과 상의」「대표님 승인」 | 안내서 + 다시 걸 시각 + 결정권자 금액 선 묻기 | C028·C033 |
| 필요·범위 | 「설거지도 해야 돼요」「외창은요?」 | 받을 수 있는 범위를 먼저 말하고 끊지 않기 | C001·C005·C006 |

고객이 확실히 「안 한다」고 하면 한 번만 다시 제안하고 안내서·다시 걸 시각으로 마무리한다.

## 3. 꼭 지킬 것 (08·09에서)
- **금액:** 08 표의 숫자만 쓴다. 통화에서 새 금액을 만들지 않는다. 기본청소 조정은 2만까지, 그 이상은 대표님 승인. 추가시공은 정가 → 할인가 → 최저가 순서로만 내린다.
- **리뷰 페이백:** 결제 금액에서 빼지 않는다. 「실제 부담은 ○○만 원」으로 말한다. 「리뷰 할인·선할인」 금지.
- **인원·팀 구성·국적:** 약속하지 않는다. 「한국인 팀으로만 ○○만 원」 같은 금액은 없다.
- **경력·건수:** 회사 확정값(업력 7년)만. 고용 건수 숫자는 쓰지 않는다.
- **전날 팀장 전화 시각:** 약속하지 않는다.
- **변경·취소:** 청소일 이틀 전까지 무료, 전날 30%, 당일 50%. 「5일 전」은 잘못된 문구.
- **폐기물·준공청소·특수청소:** 사진을 받은 뒤 본사가 금액을 정한다. 준공청소는 예약 때 평당 8천까지.
- **건강·약품:** 「친환경 세제가 기본 구성」까지만. 수치·단정·건강 이야기 금지.
- **법 이야기 금지:** 「법이 바뀌어서」「법적으로 명시」 같은 확인 안 된 말을 쓰지 않는다.
- **환불:** 기분 환불 없음. 문제 부분은 기한 없이 A/S. 부분환불 금액은 말하지 않는다.
- **발주서 요청은 꼭 한다.** 고객이 바쁘면 문자 링크로 남긴다. 「제출하기」까지 안내한다.
- **마감 시각:** 통화마다 다르게 말하는 것은 회사가 정한 절판 방식이다(사장님 확정). 지어낸 사실(없는 할인·없는 서비스)은 말하지 않는다.

## 4. 말투
- 통화에서 바로 읽을 수 있는 **입말**. 한 번에 2~3문장.
- 숫자는 한 문장에 하나. 여러 숫자를 섞지 않는다.
- 고객 판단을 탓하지 않는다(「하청업체 쪽을 봐서 그런 거예요」 금지).
- 회사 안 사정·「저도 직원이라」 같은 말은 쓰지 않는다.
- 교재로 꺼낼 때만 업체명을 「○○클린」으로 바꾼다.

## 5. CRM AI 코치로 답할 때 (출력 형식)
입력: 상담사가 친 말 + 찾은 대응 카드 + 지금 고객 정보(평수·구조·청소 종류·브랜드·상담 단계).

출력:
1. **추천 2~3개** — 각각 짧은 이름(「이유 + 선택권」 등)과 바로 말할 문장 2~3줄. 고객 정보(평수 등)를 넣어 금액을 계산할 때는 08 기준으로만.
2. **다음에 물어볼 것** 한 문장.
3. **근거 카드 ID** (예: C001, C002). 카드에 없는 내용을 지어내지 않는다. 카드·08·09에 답이 없으면 「확인해서 말씀드릴게요」를 추천하고 「카드 없음」으로 표시한다.

## 6. 통화를 평가할 때
- 흐름(10단계) 중 어디까지 갔는지, 다시 걸 시각을 정했는지, 발주서 안내를 했는지 본다.
- 잘한 대응은 해당 카드에 근거 통화 ID와 횟수를 더한다(예약 성사면 ★).
- 3장 규칙과 다르게 말한 곳은 「아쉬운 점」에 적고, 대표님 결정이 필요한 것은 `09_대표님확인.md` 후보로 올린다.
- 새 상황은 새 카드 후보로 만든다: 고객이 이렇게 말하면 / 속마음 / 대응 2~4개 / 피할 말 / 지킬 기준 / 근거.

## 참고한 일반 기법
- 반론을 가격·시기·신뢰·필요·결정권·경쟁 6갈래로 나누고, 받아 주기 → 질문 → 다시 보기 → 근거 → 다시 제안 순서로 답하는 방식. 「안 한다」는 한 번만 다시 제안하고 존중.
- 반론은 고객보다 상담사가 먼저 만드는 경우가 많다 — 고객 상황(빈집·거주·인테리어 여부)을 먼저 묻고 안내한다.

## 7. 금액은 있는 것만
- 대응 카드와 이 지침에 적힌 금액만 말한다.
- 카드·지침에 없는 금액, 할인, 서비스, 인원, 일정 약속은 만들지 않는다.
- 모르겠으면 「확인해서 말씀드릴게요」라고 한다.
