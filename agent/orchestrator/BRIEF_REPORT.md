# BRIEF — 영수증 확인용 사본

- 현금영수증·세금계산서 발급 건마다 서버에서 「확인용 사본」 PNG·PDF를 만든다. 바로빌 PopUp/Print URL은 쓰지 않는다.
- PDF는 견적서와 같은 pdfkit. PNG는 pdfkit이 그림을 만들지 못해 `@napi-rs/canvas`만 추가했다.
- 브랜드 도장(seal)이 있으면 로고로 그린다. 별도 로고 칸은 없다.
- 국세청 전송 전에는 「국세청 전송 중」. 폴링에서 승인번호가 확정되면 같은 저장 키로 다시 그린다.
- 현금영수증 취소는 취소 행의 이미지. 세금계산서 취소는 그 건을 「취소」로 다시 그린다.
- 저장 위치는 `cbiseo/tenants/{업체}/receipts/`. 목록 각 줄에 이미지·PDF·공유.
- 공유는 휴대폰에서 PNG 파일, 아니면 `/receipt/{토큰}` 복사. 토큰은 그 1건만 연다.
- 신분확인번호는 `010-****-1234`, 사업자번호는 뒤 5자리 마스킹. 가맹점 사업자번호는 영수증에 그대로 둔다.
- 마이그레이션 `20261028201000_receipt_copy`는 SQL만 두고 적용하지 않았다. 지갑 마이그레이션 `20261028193000`도 아직이다.
- 라이브 발급·공유 확인은 SQL 적용 후.
