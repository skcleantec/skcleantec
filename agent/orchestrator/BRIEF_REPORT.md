# BRIEF — 플랫폼 순발력

Phase 1·2까지 staging에 반영한다. Phase 3(업체 셀프 카드결제)은 시작하지 않았다.

- 오늘 할 일 `/platform/inbox`에서 충전·입금 확인·미납을 승인·반려한다.
- 왼쪽 메뉴에 대기 건수, 새 신청은 토스트와 소리.
- 충전·유료 전환·바로빌은 이용료 알림 메일. 입금 확인·PG는 기존 메일만 유지.
- 미납 반려는 스키마 없이 불가. 승인만 된다.
- 무료 플랜 점검은 「무료 플랜 · 과금 없음」.
- 부가서비스 요약 줄, 플랜 설명 접기, 저장 안 된 변경 막대.
- 타입 검사 통과. 브라우저 충전 알림은 로그인 세션이 없어 미확인.
