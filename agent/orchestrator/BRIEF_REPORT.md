# BRIEF — 잠금 메뉴는 자물쇠만

**요청:** 메뉴의 「Standard부터」 글자가 모바일에서 잘리니 작은 아이콘으로 **상태:** `staging`에 푸시. `main`은 안 올림.

## 한 줄 결론

상단·왼쪽·휴대폰 메뉴의 잠금은 작은 자물쇠만 보여 준다. 요금제 이름은 자물쇠 툴팁과, 메뉴를 눌렀을 때 나오는 안내 카드에 있다.

## 잘 된 점

- 상단 메뉴와 하위 메뉴가 같은 자물쇠 아이콘을 쓴다.
- 안내 카드의 「이 기능은 Standard부터 사용할 수 있습니다」와 **업그레이드 보기**는 그대로다.
- client tsc 통과. 스키마 변경 없음.
