# 발주서 설정 — 손님 화면과 같은 페이지

발주서 설정은 제목을 누르면 그 항목만 열리고, 입력 칸은 손님 발주서와 같은 번호·같은 문장으로 고칩니다.

- 상단 제목: 이름·사용, 입력 칸, 안내·동의, 손님 문구, 금액·견적, 전문시공, 유입경로. 하나만 보입니다.
- 입력 칸 1번은 「어떤 청소를 원하세요?」입니다. 질문, 도움말, 입주청소 같은 이름, 짧은 설명, 그림이 지금 손님 화면 내용으로 채워져 있습니다.
- 고치고, 선택지를 더하거나 지우고, 저장하면 손님 발주서에 반영됩니다. 안내·서명 페이지는 빼지 않습니다.
- 서버·클라이언트 타입 검사를 통과했습니다.
- 컬럼 `customer_wizard_json` 마이그레이션은 현재 `server/.env`의 DB(로컬 Postgres)에 적용했습니다. 스테이징 배포 시 preDeploy가 같은 마이그레이션을 적용합니다.
- 이 브랜치 화면은 지금 떠 있는 개발 서버와 달라 브라우저에서 클릭 확인은 하지 못했습니다.
