# BRIEF — 플랫폼 업체 상세 후속

- 기능 표 개별 설정이 기본 따름 / 켜기 / 끄기로 돌아왔다. 기능 저장은 기존 API이고, 플랜과 다른 값만 남긴다. 최종·이유는 고르는 즉시 바뀐다.
- 이유: 플랜 기본(켜짐), 상위 플랜명부터, 개별 켜기, 개별 끄기, 메뉴 숨김, 필수 기능.
- 메뉴 숨김은 모듈이 켜져 있는데 그 메뉴 경로가 전부 숨김일 때만. 지금은 메뉴 스위치가 모듈과 같아서 이 문구는 나오지 않는다.
- 배정 「미포함인데 켜짐」은 표시 오류. 접수·스케줄만 강제 포함이고 배정은 아니다. 청소비서 1인사업자(Free)에는 배정 override 행이 없고, 실제 메뉴 모듈에도 배정이 없다. 지금은 꺼짐, 이유 Standard부터.
- 개요 — 는 상세 API가 건수를 안 줘서였다. 1인 2명·5건·이달 0, 바로빌 테스트 2명·0건·0, SK클린텍 65명·3955건·이달 236.
- 설정 점검에 ✓ ⚠ ✗ 🔒 와 할 일. Free 계산서·카드결제 PG는 🔒 Standard부터. 공동인증서는 가입완료일 때만. 줄은 해당 섹션으로 이동.
- 청소비서 지갑을 알림톡 밖으로 분리. 공용 잔액과 이번 달 알림톡·현금영수증·세금계산서 사용액.
- 브라우저에서 저장 후 관리자 메뉴 반영·원복은 확인하지 못했다.
