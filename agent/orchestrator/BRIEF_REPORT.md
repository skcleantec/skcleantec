# Maestro 요약 레포트

**일시:** 2026-10-29 **요청:** 영수증·지갑 기준서 **상태:** staging

## 한 줄 결론

현금영수증·세금계산서 목록과 발행 창, 알림톡과 같은 지갑 충전 창을 기준서 배치로 바꿨다. 1,000원 칩은 서버가 시험결제를 켰을 때만 나온다.

## 잘 된 점

- 이용 순서 안내는 영수증 주소에서 숨긴다.
- 내부 메모와 실패 이유를 목록·발행 창에 넣었다.
- 충전은 컴포넌트 하나다. 카드가 기본이다.
- 서버는 환경변수가 없으면 1,000원을 거절한다.

## 주의 · 할 일

| 우선 | 내용 |
| --- | --- |
| 높음 | Railway staging 변수 이름 `PAYMENT_TEST_AMOUNT_ENABLED` 값 `true`. 넣기 전에는 칩이 안 보인다. |
| 중간 | 다시 발행은 빈 창이다. 번호는 마스킹만 저장된다. |
| 중간 | 현금영수증 메모 컬럼은 배포 시 마이그레이션으로 들어간다. |

## 테스트

1. 영수증 두 화면에서 이용 순서 안내가 없는지, 제목 줄·요약·발행 창을 기준서와 대조한다.
2. 알림톡 충전과 영수증 충전이 같은 창인지 본다.
3. 변수를 넣기 전과 후를 나눠 1,000 TEST 칩과 거절 문구를 확인한다.
