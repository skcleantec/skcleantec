# Maestro 요약 레포트

**일시:** 2026-09-21 **요청:** 안내사항 끝까지 스크롤하고 사인하면 동의 **상태:** ✅

## 한 줄 결론

손님은 안내를 맨 아래까지 내린 뒤 서명해야 안내사항 동의가 끝납니다. 체크만으로는 제출되지 않습니다.

## 잘 된 점

- 「모두 동의합니다」 제거. 서명칸 + 「서명으로 동의」
- `/info`도 같은 잠금. 서버는 서명 그림 없는 제출 거절
- 임시저장에 서명 그림을 넣지 않음
