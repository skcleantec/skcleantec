# 바로빌 화면 노출

1. 공동인증서 등록은 우리 모달의 iframe 이다. 2026-10-28 테스트에서 자동 로그인 주소(HEAD)는 200이고, X-Frame-Options 와 frame-ancestors 가 없었다.
2. 그 헤더가 막으면 가로 480·세로 720 팝업으로 연다. 주소는 클릭마다 새로 받고, 로그에는 embed 여부만 남긴다.
3. 창이 열린 동안 5초마다 등록 여부를 확인하고, 등록되면 닫은 뒤 「등록 완료 · 만료일」로 바꾼다. 닫을 때도 한 번 더 확인한다.
4. 안내 3단계는 인증서 위치, 인증서 선택, 비밀번호 입력이다. 좁은 화면에는 PC 등록 권고를 보여 준다.
5. 현금영수증만 쓰는 브랜드는 인증서 버튼을 「세금계산서를 쓸 때만 필요」 안에 접어 둔다.
6. 사장님 화면에는 바로빌 사이트 링크와 아이디·비밀번호가 없다. 충전은 청소비서 지갑, 목록은 우리 기록, 영수증 보기는 고객용 확인 주소만 연다.
7. 운영팀 연결 화면의 입력칸 안내 문구는 「회원 아이디」다. 사장님 화면에는 없다.

주의: 새 마이그레이션은 없다. 스테이징에는 아직 올리지 않았다. 실제 인증서 등록 클릭은 회원 연결 뒤 화면에서 확인한다.
