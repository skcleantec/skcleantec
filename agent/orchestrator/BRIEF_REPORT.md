# Maestro 요약 레포트

**일시:** 2026-09-09 15:35 KST **요청:** 길안내 TMAP·카카오내비 눌러도 안 열림, 코딩 정밀점검 **상태:** ✅ 원인 수정

## 한 줄 결론
폰 앱 37에는 `openNavi`가 없는데, 웹이 “있다”고 착각해 링크를 막고 빈 호출만 했습니다. 이제 **38 이상만** 내비 앱을 열고, **37은 카카오맵·구글 지도를 반드시 엽니다.**

## 잘 된 점
- 원인: Android WebView에서 없는 브릿지 메서드도 `typeof === 'function'`
- 가드: `getAppVersionCode() >= 38` 일 때만 `openNavi`
- 클릭은 항상 JS로 열고, 실패 시 https 외부 열기 폴백
