# Maestro 요약 레포트

**일시:** 2026-09-21 **요청:** 업종별 안내·추가비·위약, 발주서마다 보이고 업체가 고치게 **상태:** ✅ 구현(푸시 전)

## 한 줄 결론
입주·에어컨처럼 **발주서마다 손님 안내가 다릅니다.** 안내사항설정에서 양식을 고르고 고친 뒤 저장하면, 그 발주서를 받은 손님만 봅니다.

## 잘 된 점
- 7개 업종에 주의·추가비·출장비 기본 문구를 넣음. 위약 % 는 브랜드 설정을 따름.
- 양식 목록 **안내 고치기**, 설정 화면 발주서 칩, 「기본 문구로 초기화」.
- 손님 동의 모달·/info 가 그 발주서 안내를 연다.

## 주의 · 할 일
| 우선 | 내용 |
|------|------|
| — | 스테이징 반영은 푸시 + DB 마이그레이션 후 |
| — | 기존 양식은 목록·발급을 한 번 열면 업종 기본이 채워짐. 그다음 고치면 됨 |

## 에이전트별 한 줄
| 에이전트 | 결과 |
|----------|------|

| DesignPulse | 설정은 가로 칩, 손님은 기존 섹션 목록 |

| RoleQA | 입주/에어컨 나눠 저장·손님 화면 |
| DbSentinel | 템플릿 컬럼만. 조회에 tenantId |
