# Maestro 요약 레포트

**일시:** 2026-10-21 **요청:** PG 승인 다음 전자계약, 플랫폼 PG 메뉴와 원성 화면에 두기 **상태:** ✅

## 한 줄 결론

PG 승인이 나면 업체가 전자계약을 칸마다 작성한다. 설정은 플랫폼 결제 관리의 전자계약이고, 원성 화면에서도 약관과 작성 여부를 본다.

## 잘 된 점

- 단계는 신청, 심사, 계약, 연결이다. 승인 전에는 계약 화면이 열리지 않는다.
- 도장 사진은 종이색을 지운 그림으로 도장 칸에 들어간다.
- 스테이징에 없는 원성 메뉴는 그대로 두고 전자계약만 더했다.

|------|------|

| 확인 | 승인된 업체 화면에서 전자계약 작성이 다음인지 본다. |
