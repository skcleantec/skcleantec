**일시:** 2026-09-05 11:50 KST  
**요청:** 메시지 읽음/안 읽음이 사라진 것 같다. 전담 에이전트? 웹소켓·테스트 점검  
**상태:** ✅ 수정·API/WS 테스트 통과 (커밋·푸시 안 함)

## 한 줄 결론

메시지 전담 에이전트는 없습니다. 읽음 글자가 **묶음 전송에서 숨겨져** 있었고, 상대가 방을 열어도 **웹소켓 신호가 없어** 바로 안 바뀌었습니다. 둘 다 고쳤고 왕복 점검은 통과했습니다.

## 잘 된 점

- 관리자 말풍선: **읽음 / 안 읽음** (숫자 1 대신 글자)
- 팀장 말풍선: 묶음 전송에도 **읽음 / 읽지 않음**
- 운영 한 명이라도 보면 팀장 쪽은 읽음
- 보내기·읽기 후 `inbox:refresh` → 상대 화면이 다시 불러옴
