# 요약

**일시:** 2026-10-21 **요청:** 입력 칸 점선, 개인·법인 구분, 서류와 우편 단계 **상태:** 화면에서 점선·구분 확인, 푸시 전

## 한 줄 결론

적을 칸과 체크는 화면에서 파란 점선이고 인쇄하면 밑줄만 남는다. 개인은 신청 때 서류 3개를 올리고, 법인은 서류 4개를 원성페이먼츠 본사로 우편 발송한다. 단계는 가맹신청부터 코드 연결까지 다섯이다.

## 잘 된 점

- 점선은 화면용이다. 인쇄 CSS에서 점선과 파란 배경을 없애고 칸은 검은 밑줄만 남긴다. 맨 아래 서류 안내는 인쇄에도 남는다.
- 개인을 고르면 법인번호·법인 규모·확인 생략이 빠진다. 법인을 고르면 그 칸이 나온다.
- 개인 신청은 사업자등록증, 통장사본, 신분증이 있어야 제출된다. 법인은 그 업로드 없이 제출되고, 우편 안내가 신청서와 계약서 아래에 나온다.
- 이미 코드가 연결된 업체는 우편 시각이 없어도 연결됨으로 남는다.
