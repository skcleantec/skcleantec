# Maestro 요약 레포트

**일시:** 2026-10-29 **요청:** 카드 전액 취소 순서 **상태:** ✅ staging

## 한 줄 결론

지갑 잔액이 취소 금액보다 적으면 결제사 취소를 호출하지 않는다. 결제사 취소 뒤에 잔액·청구 반영이 실패하면 승인을 되돌리지 않고 **반영 확인 필요**로 오늘 할 일에 남긴다.

## 잘 된 점

- 지갑 결제만, 결제사 호출 전에 잔액을 본다. 부족하면 안내 문구를 내고 끝낸다.
- 입금 내역 취소 버튼 옆에 같은 문구가 미리 보인다.
- 이용료 청구 취소도 같다. 반영 실패 시 취소 상태를 유지한다.
- 1,000원 시험결제(`ac4e3129`)는 이미 staging에 있다. 이번 수정만 추가로 올린다.

## 테스트

1. 잔액이 충전액보다 적은 지갑 카드 건: 입금 내역에 사유가 보이고, 전액 취소가 비활성이다.
2. 잔액이 충분한 당일 건만 전액 취소를 누른다. 카드와 잔액이 함께 빠지는지 본다.
3. 오늘 할 일 돈 처리에 **반영 확인 필요**가 있으면 입금 내역에서 같은 건을 확인한다.
