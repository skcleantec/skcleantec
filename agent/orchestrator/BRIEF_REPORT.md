# BRIEF — 문의 링크 수정

브랜치 `feat/landing-contact-source-links`. 아직 푸시하지 않음.

- 화면 제목 「짧은 문의 링크」와 주소 안내 문구는 뺐다. **링크 생성** 모달에서 유입명·주소·브랜드·카테고리를 받고, 저장하면 목록에 카드가 생긴다.
- 카드에서 **수정**, **문의 폼 수정**. 카테고리 유형은 한줄입력·여러줄입력·숫자·선택하기.
- 선택하기의 하위 항목은 한 단계(건축물 유형 → 아파트, 오피스텔). 가로형·세로형을 고른다.
- 링크에 항목이 없으면 고객 화면은 성함·연락처·문의 내용만. 예전 `/contact` 주소는 브랜드 설정을 그대로 쓴다.
- **링크 구매**는 개수 없이 플랫폼으로 간다. 플랫폼이 개수를 정해 승인하면, 그 합 × 월 5,000원이 아직 청구서가 없는 이번 달부터 이용료에 더해진다. 무료 2개는 그대로.

새 마이그레이션 `20260923140000_landing_contact_link_custom_fields`. 이 작업트리에는 DB 주소가 없어 원격 반영은 하지 않았다. 스테이징 푸시 때 배포가 적용한다.
