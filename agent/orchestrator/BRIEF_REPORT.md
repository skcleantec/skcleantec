# Maestro 요약 레포트

**일시:** 2026-10-21 **요청:** 플랫폼에서 전자계약 작성 화면 미리보기 **상태:** ✅

## 한 줄 결론

플랫폼 결제 관리의 전자계약에서 작성 화면 미리보기를 누르면 업체가 칸마다 적는 화면이 열린다. 그 내용은 저장되지 않는다.

## 잘 된 점

- 버튼은 화면 위쪽에 있다.
- 계약서 칸과 이전·다음, 서명, 도장을 그 자리에서 확인한다.
- 칸이 본문에 없으면 계약서에 넣기로 붙인다.

## 주의 · 할 일

| 우선 | 내용 |
|------|------|
| 배포 | 스테이징 배포 후 결제 관리 → 전자계약에서 버튼을 본다. |
| 확인 | 미리보기에 적은 값이 저장되지 않는지 본다. |

## 에이전트별 한 줄

| 에이전트 | 결과 |
|----------|------|
| 조사 | 서명자 화면을 요청자가 먼저 본다 |
| 화면 | 전체 화면 미리보기. 버튼 `#0f172a` |
| 데이터 | 미리보기는 저장하지 않음. 카드번호 없음 |
