# BRIEF — 팀장 목록 공동배정

**요청:** 공동배정이 눈에 띄고 다른 팀장 전화번호가 보이게. 모바일 유지. **상태:** main 푸시.

## 한 줄 결론

팀장 배정 목록·스케줄 하루 목록·대시보드에서 공동배정은 파란 배지와 이름·전화번호 한 줄이다. 번호를 누르면 전화가 걸린다.

## 잘 된 점

- 칩은 가로 스크롤이라 카드가 아래로 늘어나지 않음.
- 상세의 담당 팀장 줄에도 번호가 보임.
- 달력 칸 작은 칩은 그대로. 날짜를 누르면 하루 목록에서 본다.
