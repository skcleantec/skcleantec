# Maestro 요약 레포트

**일시:** 2026-09-04 16:10 KST  
**요청:** 상세주소 칸이 안 보임 · 안내 동의 전 제출하기 잠금  
**상태:** ✅ 코드 반영 · 푸시 예정

## 한 줄 결론

상담사가 도로명만 넣고 상세주소를 비우면 고객에게 **상세주소 칸**이 나오고, 안내를 읽기 전에는 **제출하기가 켜지지 않습니다.**

## 잘 된 점

- 도로명 잠금 + 상세주소 비움 → 「상세주소를 알려 주세요」 질문
- 제출 오류 시 그 칸으로 이동 가능
- 문구: 「안내사항을 읽어주셔야 제출하기가 완료됩니다.」
