# Maestro 요약 레포트

**일시:** 2026-09-28 **요청:** 관리자 전용 사용자 등록에서 팀장 사원증 사진을 미리보기·다운로드 **상태:** ✅

## 한 줄 결론

관리자 전용 → 사용자 등록 → 상세·수정에서, 올린 사원증을 **미리보기**로 크게 보고 **다운로드**로 받을 수 있습니다.

## 잘 된 점

- 사진을 눌러도 크게 보고, 큰 화면에서 **사진 저장**도 됩니다
- 도움말·카탈로그에 「미리보기」「다운로드」를 그대로 적었습니다

## 주의 · 할 일

| 우선 | 내용 |
|------|------|
| 확인 | 사진이 있는 계정 → 미리보기·다운로드 |
| 확인 | 사진 없음 → 안내만, 버튼 없음 |
| 푸시 | 원하시면 스테이징에 올려 주세요 |

## 에이전트별 한 줄

| 점검 | 결과 |
|------|------|
| 타앱조사 | 올린 사진은 크게 보기 + 파일 받기가 기본 |

| 코드 | 기존 크게 보기 재사용, 페이지는 필드만 연결 |
| 설정·안내 | 끄기 없음. 도움말·카탈로그 반영 |
| 역할 | 관리자만. 마케터·팀장은 이 화면 없음 |
