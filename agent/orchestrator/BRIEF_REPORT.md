# 고객 발주서 — 코드 대신 한글, 공간 개수 한 줄

고객 발주서 확인과 제출 후 **입력 내용**에서 청소 종류·건축물 유형·건축 형태는 입주청소, 오피스텔, 신축처럼 보인다. `MOVE_IN`, `OPT_2`는 나오지 않는다.

방, 발코니, 화장실, 주방은 **구성** 한 줄이다.

제출 확인서 **확인했어요**·**닫기**는 탭이 안 닫히면 버튼 바로 위에 직접 닫으라는 안내가 나온다.

확인: 미리보기 13단계에서 청소 종류는 입주청소, 공간은 오피스텔, 구성은 `방 — · 발코니 — · 화장실 — · 주방 —` 한 줄이었다. 제출 확인서에서 확인했어요를 누르면 같은 안내가 버튼 위에 보였다.
