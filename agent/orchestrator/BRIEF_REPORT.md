# BRIEF — 세금계산서 발행 양식

- 발행은 `/admin/inquiries/receipts/taxinvoice/new`. 목록 버튼이 이 주소로 이동.
- PC는 공급자 빨강, 공급받는자 파랑 양식. 모바일은 색 띠 카드와 하단 발행.
- 150원 과금, 잔액 부족, 간이과세자 차단, 공동인증서 확인은 그대로.
- 견적서는 상호·주소·이메일만 채움. 성명·업태·종목은 견적서에 없음.
- 확인용 사본을 양식 그대로 다시 그리지 않음. 목록의 세금계산서·공유는 바로빌 주소.
- 바로빌 필드명은 WSDL에서 확인. 한글 칸 뜻과 최대 줄 수는 확인 못 함.
- 브라우저 1440·390 확인은 못 함.
