# RoleQA — 주소창 칩 / Play 앱

| 역할 | 기대 |
|------|------|
| 신규 방문자(시크릿) | 주소창 「앱에서 열기」 없음 |
| 이 PC에 웹앱이 이미 설치됨 | 칩이 **남을 수 있음** → `chrome://apps` 에서 청소비서 제거 |
| 팀장·마케터 Android | 알림 설정·로그인에서 Play 「청소비서」 배지 |
| Play 앱 WebView | 변화 없음 (네이티브 셸) |
| iPhone | 푸시 없음. 브라우저로 이용 (기존과 같음) |

회귀: 접수 목록 pin, 집계, 스케줄 취소 선반과 무관.
