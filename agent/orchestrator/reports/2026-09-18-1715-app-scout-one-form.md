# AppScout — 발주서와 접수 칸을 한 세트로

## 추천 방법
1. 칸은 **한 번만** 만든다. 손님 양식과 전화 접수가 같은 칸을 본다.
2. 접수를 열 때 **먼저 양식을 고른다**(입주청소·에어컨). 그 양식 칸만 보인다.
3. 별도 「우리 접수 칸」 스위치는 두지 않는다. Jobber처럼 두 목록을 만들면 어긋난다.

## 타 앱 작동방식
| 앱·출처 | 최신 흐름 | 우리에게 쓸 점 |
|---------|-----------|----------------|
| ServiceTitan (2026-07 help) | 칸 하나, 직무유형별로 전화예약에 표시 | 양식=직무유형, 전화=손님과 같은 칸 |
| HubSpot Forms | 폼 칸은 반드시 CRM 속성에 연결 | 접수 칸=발주서 칸=같은 저장 |
| Salesforce Record Type + Dynamic Forms | 유형이 다르면 같은 레코드라도 보이는 칸이 다름 | 한 접수건=한 양식 |
| Jobber / Housecall Pro | 요청서 질문과 잡 칸이 **따로** | 따라 하지 말 것. 변환 시 복사가 안 됨 |
| 숨고 | 고객 요청서와 고수 견적이 다름 | 우리 내부 SaaS와 다름 |

## 하지 말 것
- 전화용 스위치와 손님 양식을 따로 저장
- 사용 중인 양식이 여러 개일 때 칸을 합쳐 한 화면에 다 보여 주기(접수건이 섞임)

## DesignPulse / 구현에 넘길 한 줄
