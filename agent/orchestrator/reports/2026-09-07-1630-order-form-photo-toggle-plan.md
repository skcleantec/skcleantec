# 플랜 — 고객 발주서 사진첨부 ON/OFF

**요청:** 발주서 양식에서 고객 발주서 설정 시 사진첨부를 껐다 켰다 하고 싶다. 해당 내용이 없다.
**상태:** 플랜만. 구현 대기.

## 왜 지금 없는가

서버 카탈로그(`ORDER_FORM_SYSTEM_FIELDS`)에 이미 `photos` / 「현장 사진 첨부(섹션)」이 있다. 그런데:

1. **발주서 양식**(`AdminOrderFormTemplatesPage`)에 섹션 켜기/끄기 줄이 없다. 안내만 「켠 섹션」이고, 항목을 추가한 뒤 시스템 필드 드롭다운에서 찾아야 한다.
2. **기본 발주서**는 `isStdFieldOn`이 `isDefault`이면 **항상 true**라, 필드를 빼도 고객 화면에 사진이 남는다.
3. **발주서설정**(`order-customer-preview`)에는 전문시공 탭만 있고 사진 탭이 없다.
4. **작성 설정**(발주서 발급)에 「현장 사진」 고객 체크는 있다. 마법사만 보고, 일반 고객 폼(`OrderFormPage` 12번)은 `stdFieldOn`만 본다. 기본 양식에서는 꺼도 사진이 보인다.

사용자가 찾는 「껐다 켰다」와 세 칸 체크(고객/마케터/필수)는 다른 설정이다.

## 권장 설계

**양식별 토글 하나.** 테넌트 공통 `formConfig` 플래그나 새 Prisma 컬럼은 쓰지 않는다.

| 항목 | 결정 |
|------|------|
| 위치 | 서비스접수 → 발주서 양식 → 해당 양식 편집 |
| UI | 「항목 구성」 위 「고객에게 보일 섹션」 카드. 스위치: 현장 사진 첨부 |
| 저장 | ON이면 템플릿 필드에 `systemField: 'photos'` 포함, OFF면 제거 |
| 기본값 | **켜짐** (지금과 같게). 기존 기본 양식은 백필로 ON 유지 |
| 적용 범위 | 기본 발주서 + 내가 만든 양식 모두 |
| 이미 발급된 링크 | 양식은 발급 후 **현재 템플릿을 다시 읽음**. 끄면 미제출 고객 화면에서 즉시 사라짐 |

「작성 설정」의 고객/필수는 그대로 둔다. 양식이 OFF면 고객 체크와 무관하게 숨긴다. 필수는 사진이 ON일 때만 의미 있다.

**발주서설정에 사진 탭을 넣지 않는다.** 사진은 양식마다 다를 수 있고, 전문시공(테넌트 옵션 목록)과 성격이 다르다.

## 구현 단계 (진행 시)

1. **UI** — `AdminOrderFormTemplatesPage`에 섹션 토글 카드. 기본 양식에서도 편집 가능. 도움말: 「끄면 고객 발주서에 사진 올리는 칸이 안 보입니다.」
2. **표시 규칙** — `isStdFieldOn` / `isStdFieldOn` 복제처: 섹션 토글 키(`photos`, 필요 시 `professionalOptions`)는 `isDefault`여도 템플릿 필드 목록을 본다. 그 외 표준 칸은 지금처럼 기본 양식 전체 표시.
3. **시드/백필** — `DEFAULT_ORDER_FORM_TEMPLATE_FIELDS`에 photos 추가. 이미 있는 기본 양식에 photos 필드가 없으면 한 번 넣어 현재 ON을 유지.
4. **고객 화면** — 마법사·일반 폼·미리보기 모두 `stdFieldOn('photos')`. 일반 폼은 `customerMayEditFillKey('photos')`도 AND.
5. **서버** — `POST /by-token/:token/photos` 는 해당 양식에 photos가 없으면 거부. 목록 GET은 빈 배열 허용.
6. **필수** (이번 범위 밖 가능) — `fillRules.photos.required`면 제출 시 1장 이상. 지금은 마법사도 항상 건너뛸 수 있음.
7. **도움말** — 발주서 양식 `?` / 작성 설정 문구에 「사진 칸 자체는 양식에서 켭니다」 한 줄.

## 건드리지 말 것

- 접수 목록 「사진첨부 O/X」(고객이 올린 여부 표시)
- 상담 사진·청소 전후 현장 사진
- 양식 빌더의 입력 형식 `PHOTO`(추가 항목용) — 표준 섹션과 혼동하지 말 것
- Prisma 스키마 (불필요)

## 검증

- 기본 양식: 끄기 → 저장 → 고객 링크에 「현장 사진 첨부」 없음. 켜면 다시 보임.
- 커스텀 양식: 동일.
- F5·재로그인 후 토글 상태 유지(양식 필드 저장).
- 사진 OFF인 링크로 업로드 API 실패.
- 마케터는 양식 저장 권한 없으면 보기만.
- PC·모바일 양식 편집, 고객 마법사·일반 폼.
