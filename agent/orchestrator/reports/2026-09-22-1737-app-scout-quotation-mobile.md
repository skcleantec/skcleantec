# AppScout — 모바일 견적서 작성

**요청:** 팀장·마케터가 휴대폰에서 견적서를 쉽게 적게.

## 타 앱

- QuickBooks 견적: 손님 고르기 → **품목 하나씩 추가** → 수량·단가 → 검토·보내기.
- Reform/Baymard: 휴대폰은 **한 화면에 3~5칸**, 라벨은 위, 아래 **다음** 고정.
- Typeform: 한 질문씩. 견적은 칸이 많아서 **손님 / 품목 / 확인** 세 덩어리가 맞음.

## 가져올 것

1. 세 단계(손님·품목·확인). PC A4는 `lg` 이상만.
2. 품목은 목록에서 눌러 넣고, 수량은 +/−.
3. 큰 입력칸·전화 키패드. 저장은 아래 유지.

## 안 가져올 것

한 칸만 있는 화면을 열 개로 쪼개기. 손님이 이미 접수에 있으면 다시 고르는 화면.
