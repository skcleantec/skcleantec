# RoleQA — 작성 규칙 v2 시나리오

| 역할 | 행동 | 기대 |
|------|------|------|
| 관리자 | 설정에서 면적=마케터+필수 저장 | 전 상담사 발급에 적용 |
| 상담사 | 면적 비우고 발급 | 막힘, 면적 탭으로 이동 |
| 상담사 | 성함 탭만 보고 주소는 다른 탭 | 긴 스크롤 없이 칸만 |
| 상담사 | 설정 저장 시도 | 권한 없으면 막힘 |
| 고객 | 면적=마케터만인 링크 | 면적 질문 없음 |
| 고객 | 필수만(누구나)인 빈 칸 | 위저드에서 채워야 제출 |
| 고객 | 고객+필수, 상담사가 채움 시도 | 상담사 칸 숨김, 고객만 |
| 고객 | 옛 링크 면적 공란 | 공급/전용 추측 금지, 상담 안내 |
| 다른 업체 | 면적에 고객+필수 | 그 업체만 고객이 면적 작성 |
| F5 | `issueView=settings` / `issueSection=` | 그 화면 유지 |
| 팀장 | 해당 화면 없음 | 회귀 없음 |
