# RoleQA

| 역할 | 시나리오 | 기대 |
|------|----------|------|
| 관리자 | 사원증 있는 팀장 상세 | 사진 + 미리보기 + 다운로드 + 교체/삭제 |
| 관리자 | 사진 없음 | 「등록된 사진이 없습니다」 + 사진 올리기만 |
| 관리자 | 미리보기 | 전체 화면, 닫기, 사진 저장 |
| 관리자 | 다운로드 | 파일명 `사원증_이름` + 실제 확장자 |
| 마케터 | 관리자 전용 메뉴 | 없음 (기존) |
| 팀장 | 사용자 등록 | 없음. 본인 사원증은 팀 화면 스와이프 (기존) |

회귀: 사진 올리기·교체·삭제 그대로. 접수·스케줄 무관.
