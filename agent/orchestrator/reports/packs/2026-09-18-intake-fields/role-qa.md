# RoleQA — 우리 접수 칸 1단계

## 관리자
1. 서비스접수 → 발주서 양식 → 건축물 유형·이사일 끄고 저장
2. 접수목록에서 전화/수기 새 접수 또는 발주서 없는 접수 수정 → 해당 칸 없음
3. 기본 입주청소 발주서 손님 미리보기 → 칸 그대로

## 마케터
- 발주서 양식 권한이 있으면 같은 화면에서 저장 가능
- 권한 없으면 저장 API 거부

## 입주청소 업체
- 설정을 안 바꾸면 전화 접수도 예전과 동일(전부 표시)

## 회귀
- 내가 만든 양식에 평수만 연결한 접수는 그 양식을 따름(업체 스위치와 섞이지 않음)
