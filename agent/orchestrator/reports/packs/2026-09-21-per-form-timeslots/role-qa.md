# RoleQA — 발주서별 시간대 (정적)

실행: 코드·API 경로 추적. 브라우저 로그인 재현은 이 워크트리에 앱이 없어 **미실시**.

## 시나리오

| 역할 | 경로 | 결과 |
|------|------|------|
| 관리자 | 새 발주서 칸 만들기 | 시간대 하위 항목 편집기 있음. 1개 이상 필수 |
| 관리자 | 발주서 양식 편집 | SELECT면 같은 편집기 + 안내 문구 |
| 관리자 | 발주서설정 timeAck | 전역으로 칸을 바꾸라는 안내 아님. 양식 링크 |
| 마케터 | 발급·선입력 (`OrderFormPage` isEditor) | 양식 `preferredTime.options` 사용 |
| 고객 | 공개 발주서·제출 | 같은 목록. 서버 `isAllowedPreferredTimeValue` |
| 팀장 | 배정·스케줄·상세 | 저장된 값 표시. 커스텀은 글자 그대로. 선택 UI 없음 |
| 플랫폼 | 해당 없음 | — |

## 확대

| 항목 | 결과 |
|------|------|
| 접수 목록 수정 · 스케줄 상세 | **전역 4칸** + 지금 값만. 양식에만 있는 「저녁」을 **새로 고를 수 없음** (P2) |
| 목록 빠른 수정 | 동일 |
| 엑셀 일괄 | 여전히 오전/오후/사이/조율 매핑 (P2) |
| 사이청소 상세 시각 | 저장값이 `사이청소`일 때만 필수. 유지 |
| 핀·집계·연계 취소 | 시간대 저장만. 영향 없음 |
| 타 테넌트 | 양식은 tenantId 기존 경로 |

## 수동 확인 (배포 후)

1. 입주 양식은 네 칸, 에어컨은 오전·오후만 → 각각 발급·손님 화면
2. 사이청소 남긴 양식에서 상세 시각 필수
3. 접수 수정에서 커스텀 값이 있으면 목록에 보이는지
