# RoleQA — 고객 발주서 청소 종류

| 역할 | 시나리오 | 기대 |
|------|----------|------|
| 손님 | 링크 열기 → 5개 중 하나 고름 | 해당 그림이 바로 아래 나옴 |
| 손님 | 고르지 않고 「확인」 | 버튼 꺼짐. 다음 칸으로 안 감 |
| 손님 | 고른 뒤 「확인」 | 성함 칸으로 이동 |
| 손님 | 다른 종류를 다시 고름 | 그림만 바뀜. 확인을 다시 눌러야 다음 |
| 마케터 | 발급 화면 맨 위 같은 5개 | 고르고 선입력 저장하면 손님 첫 페이지 건너뜀(잠금) |
| 관리/팀장 | 제출된 접수 상세 | 「청소 종류」가 한글(입주청소 등)로 보임 |
| 미리보기 | 디자이너 걷기 | 「확인」은 고르지 않아도 다음 가능 |

회귀: 안내사항 섹션 체크·서명 게이트는 그대로. Prisma 새 칸 없음.
