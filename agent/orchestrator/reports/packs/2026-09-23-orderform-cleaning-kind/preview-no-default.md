# 미리보기 기본 선택 제거

**요청:** 발주서 미리보기에서 입주청소가 미리 찍혀 있음

## AppScout
생략 — 기존 카드에서 기본 선택만 제거.

## CodeGuardian
- 손님 로드는 이미 빈 값. 미리보기는 같은 손님 화면 + 고정 토큰.
- 원인: 세션 초안이 예전 입주청소를 다시 넣고, 라디오 그룹은 첫 칸을 자동으로 찍음.
- 조치: 미리보기 토큰은 초안 저장/복원 안 함. 칸은 버튼+aria-checked (라디오 input 제거).
- `client` tsc 통과.

## RoleQA
| 역할 | 경로 | 기대 |
|------|------|------|
| 관리 | 발주서설정 미리보기 | 다섯 칸 모두 비선택, 그림 없음 |
| 손님 | 새 링크 | 동일. 고르기 전 「확인」/다음 불가(미리보기는 다음 허용) |
| 상담사 작성 | 편집기 | 비어 있음. 안내용 문구만 |

## Config / Marketing
미리보기·손님 모두 처음부터 고르지 않는다고 안내 보강.
