# 미리보기 빈 시작 · 운영 반영

## 원인

발주서설정 미리보기는 고정 토큰을 쓴다. 예전에 고른 입주청소가 그 행에 남아 있으면 첫 화면이 이미 찍혀 보인다.

## 조치

- 미리보기 조회·갱신 때 청소 종류 칸을 비움
- 손님·미리보기 걷기 화면은 값을 넣지 않고 시작
- 미리보기 주소에 캐시 구분값을 붙여 옛 화면이 남지 않게 함

## 역할

| 역할 | 기대 |
|------|------|
| 관리·마케터 | 발주서설정 미리보기 — 다섯 칸 모두 비어 있음 |
| 손님 | 받은 링크 — 직접 고른 뒤에만 그림·확인 |
