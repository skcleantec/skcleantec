# AppScout — 발주서 발급에서 청소 종류 제거

## 추천 방법
1. 손님만 고르는 필수 항목은 스태프 발급 화면에 두지 않는다.
2. 처음부터 빈 선택 + 확인 후에만 다음(사전 선택 금지).

## 타 앱 작동방식
| 앱·출처 | 최신 흐름 | 우리에게 쓸 점 |
|---------|-----------|----------------|
| UX.SE 필수 라디오 | 선택이 중요하면 기본값 없음 | 입주청소 미리 체크 금지 |
| UX Patterns select | 빈 값은 완료로 치지 않음 | 고객 「확인」 필수 유지 |

## 하지 말 것
- 발급 화면에 고객 전용 피커를 남겨 입주가 찍힌 것처럼 보이게 하기

## DesignPulse / 구현에 넘길 한 줄
발주서 발급(`isEditor`)에서는 청소 종류 섹션을 숨기고, 손님 링크·고객 미리보기만 빈 피커를 보여 준다.
