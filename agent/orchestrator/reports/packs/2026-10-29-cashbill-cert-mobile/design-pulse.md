# DesignPulse — 계산서 연결 · 공동인증서 · 모바일/PC

기준: `docs/design/receipts-wallet-ui.md` 4·5, 스킬 「필수 체크 — 모바일·PC 양쪽」.

## 4. 계산서 연결

- [x] 브랜드 카드. 미가입·실패만 입력 폼. 가입완료는 요약 + 수정.
- [x] 입력은 PC 2열·최대 640px, 모바일 1열. 필수칸이 비면 바로빌 연결하기 꺼짐.
- [x] 현금영수증·세금계산서 줄을 가입완료 카드에 표시. 30일 이내 만료는 주황 「곧 만료」+ 다시 등록.
- [x] 「세금계산서를 쓸 때만 필요」 접힘 칸 제거.
- [ ] 검토 중·처리 중은 회색 배너만. 누를 다음 동작이 없어 버튼은 두지 않음.
- [x] 반려는 빨간 배너 + 다시 제출. 연결 필요는 주황 배너 + 연결하기. 실패는 빨간 배너와 입력 폼을 같이 둠.
- [x] 수정은 바로빌 재가입을 부르지 않고 청소비서 연락 정보만 저장.

## 5. 공동인증서 등록

- [x] 공용 `CashbillCertRegisterModal`. 계산서 연결 세금계산서 줄, 세금계산서 주황 배너, 제목 칩 세 곳이 연다.
- [x] 제목·닫기·Esc·3단계 안내·등록 창 열기. 모바일 회색 「PC에서 등록을 권장합니다」.
- [x] 5초마다 상태 확인, 팝업이 닫히면 한 번 더. 확인되면 배너가 사라지고 발행이 켜짐. 페이지 새로고침 없음.
- [x] 확인 실패·시간 초과는 「등록이 확인되지 않았어요」와 다시 확인·다시 열기.
- [ ] 바로빌 창을 모달 안 iframe으로 넣는 경로는 서버 `embed`가 참일 때만. 기본은 작은 팝업.

## 필수 체크

- [x] PC 1440: 카드·발행 창·충전 창 본문 최대 640px.
- [x] 모바일 390: 모달은 하단 시트, 발행·충전·인증서 주 버튼은 시트 하단. 목록은 `lg` 미만 카드.
- [x] 터치 44px: 주 버튼·닫기·목록 줄 버튼 `min-h-11` / `size-11`.
- [x] 키보드: 발행·수정·인증서 시트는 `useModalScrollKeyboardAvoidance` + `onFocusCapture`.
- [x] 가입완료는 빈 입력칸을 다시 보이지 않음.
- [x] 등록·발행·충전은 접힌 더보기 안에 없음.
- [ ] 브라우저에서 1440·390을 직접 열어 보지는 못함. 배포 후 아래 경로로 확인.
