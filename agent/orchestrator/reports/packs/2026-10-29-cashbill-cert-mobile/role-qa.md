# RoleQA

배포 전이라 스테이징 화면은 열지 않음. 카드 결제도 하지 않음.

| 역할 | 볼 곳 | 기대 |
|------|--------|------|
| 관리자 | 계산서 연결 | 미가입만 입력. 가입완료는 요약·수정. 접힘 칸 없음 |
| 관리자 | 세금계산서 | 인증서 없으면 주황 배너·제목 칩·발행 꺼짐. 등록 확인 후 배너 사라지고 발행 켜짐 |
| 마케터 | 같은 메뉴 | 계산서 연결은 관리자 전용. 영수증 목록은 기존과 같이 열림 |
| 팀장 | 해당 없음 | 이 화면 없음 |

수정 저장은 청소비서 연락 정보만 바꾼다. 바로빌 회원 정보를 다시 넣지 않는다.
