# AppScout — 플랫폼·업체 영수증 공용 양식 · 거래처

## 타 앱 작동방식
- **홈택스/얼마에요/다이렉트빌/팝빌**: 사업자번호 기준 거래처 저장 → 다음 발행 시 조회·자동완성. 발행 성공 시 신규 자동등록·기존 갱신. 공급자는 설정값(수정 불가).
- **패턴 채택**: 「거래처에서 고르기」검색(상호·번호) + 최근사용순 + 발행 시 「이 거래처 저장」기본 ON + 실패 시 미저장.

## UI 레퍼런스 (모바일)
- 피커는 시트/모달 검색 목록, 선택 시 공급받는자 칸 일괄 채움(수정 가능).
- 플랫폼 공급자 줄은 회색 read-only + 인증서 미등록 안내.

## CBISEO 적용
- 업체/플랫폼이 **같은 TaxInvoicePaper·CashbillIssueForm** (issuer adapter).
- 거래처는 `ownerType` TENANT|PLATFORM 격리.
