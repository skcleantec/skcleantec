# CardPay — 현금영수증과 카드결제 금액

카드 승인 금액은 현금영수증 한도에서 뺀다. 대상은 같은 업체·같은 접수의 `APPROVED` 합계다. 취소된 결제는 넣지 않는다.

- 현금 한도 = 총액 − 카드 승인 합계. 0 이하면 발급 버튼을 끈다.
- 카드 금액은 예약금/잔금으로 나뉘어 있지 않다. 한도 안에서 예약금을 먼저 채우고, 남은 한도를 잔금에 둔다.
- 예약금·잔금 발급이 있으면 전체 발급은 0이다. 전체 발급이 있으면 예약금·잔금은 0이다.
- 서버가 남은 한도를 금액으로 쓴다. 화면에서 금액을 더 넣지 못한다.

카드번호 입력은 없다.
