# 영수증 확인용 사본 — RoleQA (정적)

실제 발급·국세청 전송·이미지 저장은 마이그레이션 적용 전이라 실행하지 않았다. 코드 경로만 확인했다.

| 항목 | 기대 | 코드 |
|---|---|---|
| 발급 → 이미지 | 발급이 저장되면 PNG·PDF를 만들고 목록에 이미지/PDF/공유가 켜진다 | 발급 성공 후 `remember` / `rememberState` → `renderCashbillCopy` / `renderTaxInvoiceCopy` |
| 전송완료 → 재생성 | 승인번호가 새로 생기면 같은 파일 키로 다시 그린다 | 폴링이 상태뿐 아니라 `ntsConfirmNum` / `NTSSendKey` 변경도 본다 |
| 취소 이미지 | 취소 표시 | 현금영수증은 취소 행(`kind=CANCEL`)이 별도 이미지. 세금계산서는 같은 건을 「취소」로 다시 그린다 |
| 공개 링크 | 토큰 1건만. 다른 영수증은 없다 | `publicToken` 일치 1행만 조회. 토큰이 아니면 404 |
| 모바일 공유 | 그림 파일 공유, 안 되면 링크 복사 | `navigator.canShare({ files })` 후 클립보드 |

신분확인번호·공급받는자 사업자번호는 이미지와 공개 페이지에서 마스킹 값만 쓴다.
