# Phase 1 — 메뉴·이름·입금 계좌

에이전트 순서: AppScout → ConfigCurator → DesignPulse → CodeGuardian → RoleQA.

## 한 일

- 왼쪽 메뉴를 6묶음으로 바꿨다. 바닥의 설정 중복 링크는 뺐다.
- 보이는 이름: 이용료 청구, 입금 내역, 수기 카드결제, 수익 현황, 계산서(바로빌), DB 마켓, 도움말.
- 이용료 청구 위쪽 「입금 안내 (전체 공통)」를 설정 → 입금 계좌·연체로 옮겼다. 저장 API는 같다.
- 오늘 할 일은 `/platform/inbox`에서 기존 확인 화면으로만 이어 준다. 건수 API는 만들지 않았다.
- 기존 주소는 그대로다. `/platform`은 업체 목록으로 간다.

## 게이트

- 클라이언트 `tsc -b --noEmit` 통과.
- 서버 스키마는 안 바꿨다. 목록 API에 업체 id 필터만 더했다.
- 브라우저에서 메뉴를 눌러 보지는 못했다. 이 브랜치 서버를 띄우지 않았다.
