# Phase 1 — 돈 처리 순발력

## 한 일

- 플랫폼 로그인 소켓을 따로 등록하고, 충전 신청·입금 확인 요청·유료 전환·PG 가입·바로빌 검토 대기 때 화면 알림과 소리를 보낸다.
- 입금 확인 요청과 PG 가입은 원래 메일이 있으므로 메일을 한 번 더 보내지 않는다. 충전·유료 전환·바로빌은 이용료 알림 메일 주소로 즉시 보낸다.
- `GET /api/platform/inbox`가 대기 건을 모아 주고, 오늘 할 일에서 승인·반려·선택 승인을 한다.
- 충전 승인은 대기 상태를 먼저 잠근 뒤 잔액을 올린다. 이용료 입금 확인도 미납 상태를 먼저 잠근다.
- 미납·연체는 승인만 된다. 반려를 저장하려면 새 칸이 필요해서 스키마는 만들지 않았다.
- 무료 플랜 점검의 플랜·과금은 「무료 플랜 · 과금 없음」이다.
- 왼쪽 메뉴 오늘 할 일에 대기 건수가 붙는다.

## 게이트

- 클라이언트 `tsc -b --noEmit` 통과
- 서버 `tsc --noEmit` 통과
- 스키마 변경 없음
- 브라우저에서 충전 신청 → 5초 안 토스트는 플랫폼 로그인 세션이 없어 확인하지 못했다
