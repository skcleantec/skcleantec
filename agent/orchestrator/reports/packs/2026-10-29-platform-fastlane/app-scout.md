# AppScout — 플랫폼 순발력

## 추천 방법

Stripe 심사 대기열은 목록에서 금액·상태를 먼저 보고, 한 건을 열지 않아도 승인으로 큐에서 빼는 방식이다. Linear 트리아지는 사이드바 인박스에 새 항목이 들어오면 알리고, 목록에서 수락·거절한다. 청소비서 오늘 할 일도 같은 순서로 둔다. 금액과 대기 시간이 먼저이고, 승인·반려는 그 줄에서 한다.

## 타 앱

| 앱 | 하는 일 | 가져올 점 |
|----|---------|-----------|
| Stripe Radar 리뷰 | 의심 결제를 목록으로 모아 승인하면 큐에서 닫힘 | 돈 항목을 위에 두고 승인으로 즉시 제거 |
| Stripe 승인 요청 | 민감한 액션은 승인 전에는 반영되지 않고, 거절하면 변경 없음 | 확인 모달 한 번, 이미 처리된 건은 다시 반영하지 않음 |
| Linear Triage | 팀 사이드바 인박스, 수락·거절 | 왼쪽 메뉴 건수, 목록에서 처리 |
| Linear Inbox | 우선 알림과 그 외를 나눔 | 돈 처리와 검토를 두 덩어리로 |

## 모바일

한 줄에 업체명과 대기, 다음 줄에 금액, 버튼은 오른쪽에 둔다. 360px에서도 표 대신 카드.

## 하지 말 것

대기열 안에 긴 설명 문단을 넣지 않는다. 일괄 승인도 확인 없이 바로 실행하지 않는다.
