# RoleQA — 공급자 동기화

| 단계 | 관리자 | 기대 |
|---|---|---|
| 사업자정보 상호를 비우고 저장 | 저장 버튼 | 확인 창 없이 「상호를 입력해 주세요」. 회원사 상호는 유지 |
| 상호만 채우고 대표자·주소는 비움 | 같이 저장 | 상호만 회원사에 반영. 대표자·주소는 기존 값 |
| 발행 화면, 상호만 빔 | 배너·발행 | 「공급자 상호가 비어 있습니다」. 409도 같은 문장 |
| 발행 화면 다시 포커스 | 공급자 칸 | 브랜드 공급자를 다시 읽음. 작성 중인 품목은 유지 |
| 공급자 정보 수정 | 모달을 열 때 | 서버 최신 값. 모바일 버튼 높이 44px |
| 팀장 | 이 화면 없음 | 사업자정보·발행 화면은 관리 쪽 |

다른 업체 브랜드 id 수정은 기존처럼 403. 스테이징에서 빈 상호를 실제 값으로 되돌리는 저장은 하지 않았다.
