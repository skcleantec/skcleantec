# RoleQA — 발주서설정 한 화면

| 역할 | 시나리오 | 기대 |
|------|----------|------|
| 관리 | 서비스접수 → 발주서설정 | 왼쪽 미리보기, 오른쪽 섹션. 탭 10개 없음 |
| 관리 | 입주청소 고름 | 오른쪽 이름·칸·안내가 입주 |
| 관리 | 에어컨 고름 | 칸·시간대·안내가 에어컨. 미리보기도 같이 |
| 관리 | 금액 저장 | 「모든 발주서」. 입주·에어컨 미리보기 금액 라벨 같음 |
| 관리 | + 새 발주서 | 업종 마법사. 끝나면 설정 화면으로 |
| 관리 | 옛 /order-templates | 같은 설정 화면으로 이동 |
| 마케터 | 같은 화면 | 양식 사용 끄기/삭제는 기존과 같음 |
| 팀장 | 해당 없음 | 메뉴 없음 |
| 회귀 | 새로고침 | 고른 발주서·펼친 섹션 유지 |
