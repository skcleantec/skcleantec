# CodeGuardian — 세금계산서 발행 양식

- 과금·잔액 부족·간이과세자·공동인증서 확인은 기존 `issueTaxInvoice` 를 그대로 호출.
- 테넌트 조회는 `tenantId` 유지. 접수 매칭 `inquiryId` 도 테넌트 조건.
- 바로빌로 보내는 현금·수표·어음·외상·비고·종사업장·품목 줄은 WSDL에 있는 필드명만 사용.
- 한글 칸 뜻은 확인 못 함. 최대 줄 수 상한도 확인 못 함이라 화면은 16줄에서 멈춤.
- 확인용 사본 그림을 6-2 양식으로 다시 그리지 않음.
- 견적서에는 상호·이메일·주소만 있어 성명·업태·종목 자동 채움은 없음.
