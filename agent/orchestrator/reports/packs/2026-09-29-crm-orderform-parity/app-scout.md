# AppScout — CRM에서 견적을 작업서로

## 추천 방법
1. CRM은 **별도 발주서 화면을 만들지 않고** 본업 발급 폼을 연다.
2. 상담에서 이미 있는 값(이름·금액·일정)만 넘긴다.
3. CRM에 없는 칸(시간대 등)은 발급 폼에서 고르게 둔다.

## 타 앱 작동방식
| 앱·출처 | 최신 흐름 | 우리에게 쓸 점 |
|---------|-----------|----------------|
| Dynamics 365 Field Service | 견적/기회 → 작업서, 고객·금액 이관 | 같은 작업서 모델 |
| Salesforce Field Service | 견적이 CRM으로 동기화되며 주문 생성 | 견적 연결은 부가, 발급이 본선 |
| Zoho CRM+FSM | 승인 견적 → Work Order | 링크는 best-effort |

## 하지 말 것
- CRM용으로 시간대·양식을 다른 규칙으로 다시 만들기

## DesignPulse / 구현에 넘길 한 줄
현재 구조(서랍 + 동일 발급 폼)가 레퍼런스와 맞음. 이번엔 코드 변경 없음.
