# AppScout — 결제창 3종(고객 링크·팀장 방법·수기·공유·완료) 밝은 테마 리디자인

## 추천 방법
1. 밝은 바탕 + 흰 카드 + 하단 고정 CTA에 금액을 넣는 원페이지 체크아웃.
2. 결제 방법 선택은 **두 카드가 동시에 남고** 선택만 강조(남색 테두리·체크)한 뒤 「다음」.
3. 금액은 화면에서 가장 크게, CTA 문구에 금액을 다시 적는다.

## 타 앱 작동방식
| 앱·출처 | 최신 흐름 | 우리에게 쓸 점 |
|---------|-----------|----------------|
| Design Lounge one-page checkout | 요약 → 방법 카드 → 고정 Pay | 하단 고정·금액 반복 |
| Appetite UI Checkout | 총액 직전 + 행위형 버튼 | 「N원 결제하기」「승인 요청」 |
