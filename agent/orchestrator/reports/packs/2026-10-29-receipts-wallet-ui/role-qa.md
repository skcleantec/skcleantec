# RoleQA

브라우저로 staging을 열지는 못했다. 배포 후 화면 대조는 별도다. 타입 검사는 서버·클라이언트 통과.

| 역할 | 볼 것 |
| --- | --- |
| 관리자 | 현금영수증·세금계산서 제목 줄, 요약 3장, 발행 창, 충전 창 |
| 관리자 알림톡 | 충전 버튼이 같은 창 |
| 마케터 | 충전 버튼이 관리자만. 「관리자만 충전할 수 있습니다」 |
| 팀장 | 이 메뉴 없음 |
| 환경변수 없음 | 1,000 TEST 칩 없음. 1,000원 요청은 거절 |
| 환경변수 true | 칩이 보이고, 그 금액만 기존 5만 원 단위 검사를 통과 |

세금계산서 인증서 없는 브랜드는 주황 배너와 발행 비활성.
