# DesignPulse — 기준서 대조

기준서 `docs/design/receipts-wallet-ui.md`만 따른다. AppScout는 이번 작업지시서에 없다.

- 목록: 제목 줄에 지갑·충전·발행. 요약 카드 3장. 당일·이번주·월별·날짜. 고객 칸에 이름·번호·접수 링크. 실패 이유. 버튼 1개와 ⋯.
- 발행: 560px 시트, ①~⑤, 접힌 내부 메모, 하단 비용·잔액.
- 충전: 영수증·알림톡이 `WalletChargeModal` 하나. 기본 카드. 1,000 TEST는 서버가 켜 줬을 때만.
- 이용 순서 안내는 `/receipts`에서 숨김.
- 못 맞춘 것: 다시 발행은 빈 창만 연다. 식별번호는 마스킹만 저장돼 채울 수 없다. 세금계산서 승인번호 칸은 국세청 전송키다. 별도 승인번호 필드는 없다.
