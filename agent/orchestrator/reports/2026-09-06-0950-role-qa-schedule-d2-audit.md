# RoleQA — 고객이 어떻게 확인하나

| 역할 | 확인 |
|------|------|
| 관리자 | 알림톡 → 「무위약 마감일 (자동)」켜짐 · 「최근 일정 확인 알림 발송」표 |
| 관리자 | 영업브랜드 → 위약금 → 「위약 없이 바꿀 수 있는 마지막 날」 |
| 고객 | 카카오 알림톡, 낮 12시 이후, 마감일=오늘인 예약건 |
| 팀장 | 이 알림 없음 (해피콜 FCM과 다름) |

## 수동 시나리오

1. 청소일 = 모레, 브랜드 마지막 날 = 2일 전 → **오늘 12시**에 와야 함
2. 청소일 = 내일, 마지막 날 = 2일 전 → **어제**에 나갔어야 함 (오늘은 안 감)
3. 청소일 = 내일, 마지막 날 = 1일 전(전일) → **오늘 12시**
