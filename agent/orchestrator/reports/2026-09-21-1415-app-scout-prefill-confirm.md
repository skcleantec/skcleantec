# AppScout — 상담사가 적은 값을 손님 단계에서 다시 보여 확인

## 추천 방법
1. 선입력된 칸을 **건너뛰지 않는다.** 한 화면씩 값을 보여 주고 **다음**으로 확인한다.
2. 이미 적힌 칸은 **잠금**(고칠 수 없음). 빈 칸·0만 손님이 적는다.
3. 안내: 「상담에서 적어 둔 내용입니다. 맞으면 다음을 눌러 주세요.」

## 타 앱 작동방식
| 앱·출처 | 최신 흐름 | 우리에게 쓸 점 |
|---------|-----------|----------------|
| Stripe Connect onboarding | 미리 채운 정보를 보여 주고 확인 | 숨기지 않고 확인 |
| Nextmatter 4-eye | 선입력 값을 검토자가 보고 확인 | 점검 = 보고 다음 |
| Tesouro onboarding | 선입력 후 사용자가 봄 | 값은 화면에 있어야 함 |

## 모바일 인기 디자인 레퍼런스
| 순위 | 출처 URL | 왜 인기인가 | 가져올 패턴 |
|------|----------|-------------|-------------|
| 1 | https://docs.stripe.com/connect/embedded-onboarding | 실서비스 온보딩 | 선입력 확인 후 다음 |
| 2 | https://nextmatter.mintlify.app/docs/prefills | 업무 폼 4-eye | 숨기지 않음 |

## 하지 말 것
- 선입력 칸을 질문 목록에서 빼기
- 잠긴 값을 손님이 바꾸게 열기

## DesignPulse / 구현에 넘길 한 줄
잠긴 숫자는 회색 칸에 또렷이 두고, 하단에 **다음**만 켠다.
