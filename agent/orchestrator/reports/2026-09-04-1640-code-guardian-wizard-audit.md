# CodeGuardian — 고객 발주서 정밀점검

**일시:** 2026-09-04 16:40 KST

## 대조 기준

제출 `handleSubmit` 필수 항목마다 위저드 질문이 **숨기면 안 되는지** 확인.

| 항목 | 이전 | 조치 |
|------|------|------|
| 성함 | 공백만 잠기면 칸 없음 | 공백이면 질문·수정 |
| 주소·상세 | 이미 수정됨 | 유지 |
| 전화·보조 | 보조 미잠금 시 질문 | 유지 |
| 이메일 | 오기재도 잠금 | 형식 맞을 때만 잠금 |
| 건축물 | 둘 다 열려야 질문 | 한쪽만 열려도 질문 |
| 면적 | 평수 잠기면 기준도 잠김 | 기준은 areaBasis만 |
| 일정 | 날짜 있으면 시간·시각 통째 숨김 | 날짜/시간/시각 분리 |
| 방 개수 | 이미 수정됨 | 유지 |
| 입주 | 이미 OR 노출 | 유지 |
| 안내·제출 | 이미 수정됨 | 유지 |

## Commands

- `npx tsc -b --noEmit` 통과
- `node scripts/build-help-data.mjs` 통과
