# AppScout — 관리자 전용 메뉴마다 쉬운 도움말

## 추천 방법
1. 각 화면에서 `?`를 누르면 그 메뉴만 설명한다.
2. 짧은 문장·줄바꿈·아이콘으로 한 화면 분량만.
3. 버튼 이름은 화면에 보이는 글자 그대로.

## 타 앱
| 출처 | 흐름 | 쓸 점 |
|------|------|--------|
| GitLab Pajamas | 물음표 → 지금 화면 설명 | 메뉴마다 다른 내용 |
| NN/g | 사용자가 원할 때만 연다 | 자동 팝업 금지 |
| Apple Tips | 한두 문장·행동 중심 | 긴 매뉴얼 금지 |
