## 설정 위치

| 항목 | 어디 |
|------|------|
| 위약 % · 당일/전일 | 영업브랜드 → 위약금 탭 (기존) |
| 안내 본문 공통 | 발주서설정 → 안내사항 (`?panel=guide`) |
| 안내 취소·변경만 브랜드별 | **같은 안내사항 화면** + 브랜드 탭 (신규) |
| 끄기 | 해당 없음. 빈 덮어쓰기 = 공통 사용 |

`userConfigurable: true` — 업체가 브랜드마다 예약금 문장을 달리 씀. 행 숨김/색 토글 아님.
