# AppScout — 발주서 켜기·끄기가 한눈에

**일시:** 2026-09-18 17:40  
**업무:** 목록에서 양식을 켜고 끄는 방법이 안 보임

## 타 앱

- Typeform: 목록에서 폼을 보고, 켤지 말지는 **Share / Publish** 큰 버튼. 작은 스위치만 두지 않음.
- Google Forms: 응답 받기는 **큰 토글 + 「응답 받는 중」 글자**.
- 모바일 폼 목록: 카드 + 상태 칩 + 카드 안 큰 액션. 표 안 작은 스위치는 잘 안 보임.

## 가져올 것

- 목록을 **지금 쓰는 / 안 쓰는** 두 덩어리로 나눔
- 카드마다 **사용하기 / 사용 끄기** 큰 버튼
- 「발주서 목록」(이미 보낸 것)과 「발주서 양식」(켜기·끄기)을 문구로 구분

## 버릴 것

- 표 한 칸에 숨긴 작은 스위치만으로 켜기
- 발주서 목록에서 양식을 켜게 하는 것(이미 보낸 서류 목록과 섞임)
