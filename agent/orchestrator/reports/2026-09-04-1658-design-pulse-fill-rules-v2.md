# DesignPulse — 발급 안 제목 탭 + 설정

## 레이아웃 (발주서 발급 카드 안)

```
발주서 발급   [?]                          [설정]
[성함] [주소] [연락처] [면적] [일정] …     ← 가로 스크롤 탭
(설정 켬) 규칙 표 / (끔) 해당 제목 칸만
```

- **설정은 목록·후속과 나란한 탭이 아님.** 제목 줄 오른쪽 버튼. 켜면 본문이 설정 페이지로 바뀜.
- 제목 탭: 지금 폼 번호와 동일 — 성함, 주소, 연락처, 면적, 청소일, 시간대, 시각, 공간, 건물상태, 이사일, 특이사항, 사진, 전문시공.
- 모바일: `flex-nowrap overflow-x-auto`, `text-fluid-2xs`, 설정은 항상 보이게 `shrink-0`.
- 선택 탭 `bg-slate-900 text-white`. 설정 활성도 동일.

## 설정 페이지

- PC: 표. 열 = 항목 | 고객 | 마케터 | 필수. `th` 가운데, 체크 `td` 가운데.
- 모바일: 카드 — 항목명 1줄, 체크 3개 한 줄.
- 면적 행 위 호박 한 줄: 공급·전용은 고객이 구분하기 어려움.
- 저장: 하단 `slate-900`. hover / focus-visible / disabled.
- 범례 접기: 「필수만 = 둘 중 한 명」「고객+필수 = 고객만 그리고 꼭」

## 작성 탭

- 마케터 불가 칸: 숨기거나 회색 「고객이 작성합니다」.
- 마케터+필수 빈 칸: 라벨 옆 「필수」, 발급 시 그 탭으로 이동.
