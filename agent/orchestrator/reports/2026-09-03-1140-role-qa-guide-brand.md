# RoleQA — 구현 후 시나리오

| Step | 기대 |
|------|------|
| 공통에 예약금 미반환 줄 저장 | 새로고침 후에도 유지 |
| 브랜드A만 저장 | 브랜드A 발주서·`/info?brand=A`만 다름 |
| 공통 문구 사용 | 덮어쓰기 삭제, 공통으로 복귀 |
| `/info` brand 없음 | 공통 추가 줄 + 기본 브랜드 위약 % |
| 브랜드 1개 | 탭 숨김, 공통만 |

회귀: 옛 전일 30% 정확 문장만 코드와 중복 제거.
