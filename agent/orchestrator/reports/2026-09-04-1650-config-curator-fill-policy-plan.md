# ConfigCurator — 작성 규칙 설정 위치

## 어디에 두나

| 후보 | 결정 |
|------|------|
| 발주서 발급 상단 탭 | **채택** — 발급과 같은 화면, URL 유지 |
| 발주서설정 11번째 패널 | 비채택 — 이미 제목·안내·시공 등으로 붐빔 |
| 설정 → 화면 표시 | 비채택 — 색/배지 허브이지 업무 규칙 아님 |
| 발주서 양식 fillMode | **보조만** — 칸 표시. 발급 허용은 작성 규칙 |

## 권한

- 조회: 발급 가능한 스태프
- 저장: `orderform.formConfig` (관리자). 마케터 편집은 제품 확인 후.

## 도움말

- 발주서 발급 `?` 에 「작성 규칙」 절 + FAQ
- 토글로 숨기면 안 됨 (견적·위약과 직결)
