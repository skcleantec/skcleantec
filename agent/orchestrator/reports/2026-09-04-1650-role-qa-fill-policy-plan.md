# RoleQA — 작성 규칙 시나리오 (구현 후)

| 역할 | 행동 | 기대 |
|------|------|------|
| 관리자 | 작성 규칙에서 면적=마케터 필수 저장 | 전 마케터 발급에 적용 |
| 마케터 | 면적 비우고 발급 | 막힘, 면적 칸으로 이동 |
| 마케터 | 공급+평수 넣고 발급 | 링크 생성, 고객은 면적 수정 불가 |
| 고객 | 면적 있는 링크 | 면적 질문 없음·읽기만 |
| 고객 | 옛 링크 면적 없음 | 제출 불가, 상담사 확인 안내 (추측 입력 금지) |
| 다른 업체 | 면적을 고객 작성으로 바꿈 | 그 업체만 고객이 면적 입력 |
| F5 | `?tab=fillPolicy` | 작성 규칙 탭 유지 |
| 팀장 | 해당 화면 없음 | 회귀 없음 |
