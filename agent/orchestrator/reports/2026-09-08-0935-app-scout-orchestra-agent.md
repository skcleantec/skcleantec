# AppScout — 오케스트라가 주문마다 타 앱·인기 모바일 UI를 먼저 조사하게 한다

## 추천 방법
1. 구현·화면 잡기 전에 **검색 → 페이지 진입 → 인기 항목만** 레퍼런스로 고른다.
2. 작동방식은 동종(현장·예약·청소·일정·고객 폼)의 **최신 플로우**를 먼저 적는다.
3. 디자인은 **모바일 갤러리(실앱)를 데스크톱 컨셉보다 우선**한다.
4. 패턴만 넘긴다. 픽셀 복붙·우리 토큰 무시 금지.

## 타 앱 작동방식
| 앱·출처 | 최신 흐름 | 우리에게 쓸 점 |
|---------|-----------|----------------|
| Dynamics 365 Field Service 모바일 | 일정에서 상태·길찾기 한 탭. 상세는 탭 스와이프. 하단 고정 CTA. 작업 탭에 진행 막대·큰 체크 | 팀장 일정·배정: 한눈에 상태 + 하단 핵심 버튼 |
| VP0 / 현장 기술자 앱 패턴 | 오늘 일 목록 → 체크리스트 → 전후 사진 → 서명. 선형·오프라인 전제 | 현장 사진·점검: 단계 건너뛰기 막기, 큰 터치 |
| Viator (Mobbin 2026 신규 앱 큐레이션) | 결제 전 「다음에 무슨 일이 일어나는지」를 보여 줌 | 고객 발주·예약: CTA를 「계속」보다 「내용 확인」처럼 |
