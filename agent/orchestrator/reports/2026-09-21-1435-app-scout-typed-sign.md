# AppScout — 성함 타이핑 후 손글씨 서명 동의

## 추천 방법
1. 위에 **성함 입력**, 아래에 **손글씨 서명**, 그다음 「서명으로 동의」.
2. 확인용 발주서에 타이핑 이름 + 서명 그림을 한 카드로 둔다.
3. 안내·위약 각 구역 아래에 「고객님이 읽고 동의하셨습니다」를 넣는다.

## 타 앱
| 출처 | 흐름 | 쓸 점 |
|------|------|--------|
| Adobe Scribble / SignNXT | 이름 타이핑 + 그리기 | 위 타이핑, 아래 사인 |
| UX Patterns Signature Pad | 패드 + 무엇에 서명하는지 | 동의 문구를 패드와 같이 |
| Formstack | 타이핑·그리기 병행 | 둘 다 남김 |

## 하지 말 것
- 타이핑만으로 동의 끝내기
- 확인서에서 서명만 있고 타이핑 이름이 빠지기
