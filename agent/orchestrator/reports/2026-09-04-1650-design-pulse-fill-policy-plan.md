# DesignPulse — 작성 규칙 탭

## 화면

- **발주서 발급** 기존 세그먼트 옆에 **작성 규칙** (`issue` / `fillPolicy` / `followup` / `list`).
- 선택: `bg-slate-900 text-white`, 모바일 `text-fluid-2xs`.
- 본문: PC 표(항목 · 마케터 필수 · 고객 작성), `th` 가운데, 모바일 카드 2줄.
- 면적 행 상단 고정 + 호박 한 줄: 「공급·전용은 고객이 구분하기 어렵습니다. 기본은 상담사가 적습니다.」
- 저장: 하단 Primary `slate-900`. 모달은 **첫 방문 안내만**(선택), 설정 본체는 탭.

## 발급 폼

- REQUIRED 빈 칸: 라벨 옆 「필수」, 발급 버튼 시 같은 오류 모달 패턴.
- 고객: 면적 잠금 시 회색 읽기 상자(도로명 잠금과 동일).
