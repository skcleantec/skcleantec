# 청소비서 마케팅 가이드 — 다른 AI와 공유하는 법

이 폴더는 **청소비서(CBISEO)** 화면을, 광고·카드뉴스·랜딩 페이지를 만드는 **다른 AI**가 읽도록 정리한 곳입니다.

소스코드를 몰라도 됩니다. 아래 파일을 채팅에 붙이거나 폴더 ごと 넘기면 됩니다.

## 넘길 파일 (권장 순서)

1. **`README.md`** (이 파일) — 역할 안내
2. **`BRAND.md`** — 로고, 브랜드 색, 쓰면 안 되는 이름
3. **`CATALOG.md`** — 메뉴 전체와 쉬운 설명
4. 자세히 그릴 화면이 있으면 **`menus/`** 안 해당 파일  
   - 스케줄(달력·일정 색): `menus/schedule.md`  
   - 서비스접수(목록 색): `menus/inquiries.md`

기계가 읽게 하려면 **`catalog.json`** 을 같이 주세요.

## 다른 AI에게 붙여 넣을 프롬프트 예시

```
너는 청소비서(입주·이사 청소 업체를 위한 업무 앱)의 마케팅 담당이다.
첨부한 가이드만 근거로 글을 쓴다. 가이드에 없는 기능은 만들지 않는다.
색을 쓸 때는 가이드의 hex를 그대로 쓴다. 비슷한 색으로 바꾸지 않는다.
버튼·메뉴 이름은 가이드에 적힌 화면 글자를 그대로 쓴다.
제품명은 청소비서 또는 Cbiseo만 쓴다. SK클린텍이라고 부르지 않는다.
일반인이 이해하는 말로 쓴다.
```

그다음 원하는 결과물을 적습니다. 예: 「스케줄 화면을 소개하는 인스타 카드 3장 문구」, 「오전·오후 색이 보이게 배너 시안 설명」.

## 이 문서가 자동으로 바뀌는 이유

앱에 **새 메뉴나 색**이 생기면, 개발 에이전트(MarketingAgency)가 이 폴더를 같이 고칩니다.  
글을 만들기 **직전**에 `CHANGELOG.md` 맨 위 날짜가 최근인지 확인하세요.

## 이 폴더가 아닌 것

| 문서 | 용도 |
|------|------|
| `agent/product/HELP_GUIDE_TEAM.md` | 팀장이 앱을 **쓰는** 도움말 |
| `agent/config-curator/` | 화면 표시를 **켜고 끄는** 내부 목록 |
| 이 폴더 | **외부·다른 AI**용 마케팅 설명 |
