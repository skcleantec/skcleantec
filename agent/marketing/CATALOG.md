# 청소비서 — 메뉴·기능 카탈로그 (마케팅·다른 AI용)

갱신일: **2026-09-19**  
제품: 청소비서 (CBISEO). 입주·이사 청소 업체 업무 앱.

이 문서는 **화면에 있는 것**만 적습니다. 없는 기능을 지어내지 마세요.  
색이 중요한 화면은 `menus/schedule.md`, `menus/inquiries.md`를 함께 읽으세요.

---

## 1. 앱이 하는 일 (쉬운 말)

손님이 청소를 맡기면, 업체는 보통 이렇게 일합니다.

1. **받기** — 전화·링크·엑셀로 손님 정보를 남긴다. (서비스접수)
2. **돈·서류** — 예약금, 발주서, 견적서를 맞춘다.
3. **언제 갈지** — 달력에 오전/오후를 넣고 팀장에게 넘긴다. (스케쥴)
4. **현장에서** — 팀장이 배정 목록을 보고, 사진·검수·메시지를 한다.
5. **끝난 뒤** — 정산, 광고비, 리뷰 페이백, 다른 업체와 일 나누기.

청소비서는 이 흐름을 **한 로그인**으로 이어 줍니다.

---

## 2. 들어가기

1. 브라우저에서 청소비서 사이트에 접속한다.
2. **업체 코드** + **아이디** + **비밀번호**로 로그인한다.
3. 권한에 따라 **관리 화면** 또는 **팀장 화면**이 열린다.
4. 위쪽(또는 휴대폰에서는 아래·옆 메뉴)에서 원하는 이름을 누른다.

새로고침해도 **지금 보던 메뉴**에 그대로 있는 것이 정상입니다.

| 서비스접수 | `/admin/inquiries` | 손님 접수 전부. 아래 하위 메뉴가 많음 | `menus/inquiries.md` |
| 스케쥴 | `/admin/schedule` | 날짜별 오전·오후 일정과 배정 | `menus/schedule.md` |

| 관리자 전용 | `/admin/team-leaders` | 사람·브랜드·정산·설정 (관리자만) | 이 문서 §6 |

### 3.1 서비스접수 안에서 한 번 더

경로 예: `로그인 → 상단 「서비스접수」 → 왼쪽(또는 햄버거)에서 이름 선택`

| 그룹 | 화면 글자 | 쉬운 설명 |
|------|-----------|-----------|
| — | 접수목록 | 손님 접수 표. 위쪽에 미제출·입금 건이 색으로 고정 |
| — | 부재·보류 | 전화 못 받은 건, 잠시 멈춘 건 |
| — | 페이백/리뷰 | 리뷰 이벤트·페이백 |
| 카드결재 | 결제 내역 | 카드로 받은 결제 목록 |
| 카드결재 | PG 연동 | 카드 결제 회사 연결 |
| — | C/S 관리 | 청소 후 손님 문의·A/S |
| — | 문의내역 | 웹 등으로 들어온 문의 |
| 발주서 | 발주서 목록 | 손님에게 보낸 작성 링크 목록 |
| 발주서 | 발주서 발급 | 새 링크를 만들어 손님에게 보냄 |
| 발주서 | 발주서 양식 | 목록에서 **사용하기/사용 끄기**. 안 쓰는 내가 만든 양식은 **삭제**. **입주청소 기본**은 끄기만. 사용함만 손님·접수에서 고름. **새 발주서**는 업종 → 이름 → 칸 만들기 → 확인. 업종을 고르면 그 일 칸이 미리 들어감 |
| 발주서 | 고객링크설정 | 링크 안내 문자 문구 |
| 발주서 | 발주서설정 | 안내문·견적 옵션 미리보기. 미리보기에서 **다음**을 필수 없이 넘김(제출 안 됨) |
| 견적서 | 견적 목록 / 작성 / 설정 | 견적서를 만들고 보냄 |
| 일괄접수 | 매칭 서식 / 일괄 등록 / 실행 이력 | 엑셀로 여러 건을 한 번에 넣음 |

### 3.2 카드결재 안내 (마케팅 시)

손님 **카드번호는 청소비서 화면에 입력하지 않습니다.** 결제 창(원성페이먼츠)에서만 입력합니다.  
광고 시안에 카드번호 입력칸을 그리지 마세요.

## 4. 팀장 메뉴

화면 글자: **대시보드, 배정목록, 스케줄, 정산, 가계부, 정보공유, 휴무일, C/S, 메시지**  
휴대폰 아래 탭(자사 팀장): **홈, 배정, 스케줄, 가계부, 메시지** (타업체 팀장은 가계부가 없을 수 있음)

| 메뉴 글자 | 경로 | 쉬운 설명 |
|-----------|------|-----------|
| 대시보드 | `/team/dashboard` | 오늘 알림·오늘 일정 요약 |

| 스케줄 | `/team/schedule` | 내 달력. 관리자 「스케쥴」과 같은 일을 **내 것만**. 평수·방·추가 칸도 같은 발주서 |
| 정산 | `/team/settlement` | 타업체로 온 일의 정산 (기능이 켜진 업체) |

팀장 달력의 색은 관리자 스케쥴과 **같은 오전(노랑)·오후(하늘)** 느낌을 씁니다. 자세한 hex는 `menus/schedule.md`.

## 5. 나머지 관리 메뉴 (쉬운 설명)

### 대시보드

- **경로:** `로그인 → 상단 「대시보드」`
- **하는 일:** 오늘·이번 달 숫자, 처리할 알림을 한눈에.
- **마케팅 포인트:** “새로고침 없이 숫자가 따라온다” — 현장에서 바로 보는 홈.

### 정보공유

- **경로:** `로그인 → 상단 「정보공유」`
- **하는 일:** 우리 업체가 못 가는 날을 **다른 청소 업체**에 넘기거나, 반대로 받아 옵니다. 장바구니처럼 올리고 확정합니다.
- **색:** 스케줄 목록에서 이 건은 **보라 계열 구역**으로 묶입니다 (`#8b5cf6` 점, 배경 `#f5f3ff`).

### 광고비

- **경로:** `로그인 → 상단 「광고비」` → (관리자면) 「설정」
- **하는 일:** 채널별 광고비를 모아 보고, 정산 규칙을 정합니다.

### 메시지

- **경로:** `로그인 → 상단 「메시지」` (팀장은 `「메시지」`)
- **하는 일:** 직원끼리 업무 연락. 관리자·마케터 대화 목록 맨 위에 **「청소비서 운영팀」** 이 있습니다. 이용·기능 문의는 여기로 보냅니다. 운영팀이 답하면 같은 방에 보입니다. 팀장 화면의 메시지는 사내 연락만입니다.

## 8. 공개 손님 화면 (직원이 아닌 사람)

직원이 링크를 보내면 손님이 로그인 없이 엽니다.

| 하는 일 | 쉬운 설명 | 버튼 색 |
|---------|-----------|---------|

## 9. 플랫폼(청소비서 운영팀) 메뉴

업체 직원 광고에는 보통 **넣지 않습니다.** 운영 화면입니다.

업체 관리, 추천인, 결제 관리, 가입 체험 이벤트, 안내팝업, 정보공유, **메시지**(업체와 개별·전체 대화, 안 읽으면 호박색 숫자 `#fbbf24`), 고객센터, 도움말 CMS, 지원 접속.

## 10. 다른 AI를 위한 주의

1. 관리자 메뉴 이름은 **「스케쥴」**(ㅠ), 팀장은 **「스케줄」**.
2. 「연계 취소됨」 배지만 있고 일정이 살아 있는 것처럼 그리지 마세요. 받은 쪽 접수는 **취소 칸**으로 갑니다.
3. 색을 “예쁘게” 바꾸지 마세요. 오전을 파랑으로 바꾸면 **앱과 다른 제품**이 됩니다.
4. 새 기능은 `CHANGELOG.md`를 먼저 보세요.
