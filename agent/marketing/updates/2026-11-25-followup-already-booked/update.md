# 부재·보류에 「이미 예약」 표시

- 날짜: 2026-11-25
- 위치: 서비스접수 › 부재·보류, 텔레CRM 부재보류
- 대상: 관리자·마케터

## 무엇이 바뀌었나
- 이미 접수(예약)된 고객이 부재·보류 목록에 남아 있으면 「이미 예약 · 날짜」 빨간 표시가 붙고 번호에 줄이 그어짐. 이미 예약했는데 또 전화하는 일을 막기 위함.
- 같은 사람인지는 전화번호뿐 아니라 이름·주소(지역·단지)·건물 유형·평수와 구조·희망일을 함께 보고 판단. 일부만 같으면 노란 「예약 의심」.
- 다른 브랜드로 예약한 고객은 「○○로 예약됨」 표시만 붙고 목록에는 그대로 남음.
- 예전에 이용이 끝난 고객이 다시 문의하면 「지난 이용 고객」으로 알려 줌(막지 않음).
- 텔레CRM에서 이미 예약한 고객에게 「전화」를 누르면 한 번 더 확인.
- 접수가 새로 생기거나 상태가 바뀌면(발주서 발급·제출, 배정 포함) 같은 브랜드의 부재·보류는 목록에서 자동으로 내려감. 입금대기 접수 고객도 접수 목록에서만 챙김.
- 접수가 취소되면 자동으로 내려갔던 부재·보류는 다시 올라옴.
