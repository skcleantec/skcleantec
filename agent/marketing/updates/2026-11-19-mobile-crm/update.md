# 모바일 CRM — 내 문구 탭, 메인에서 바로 열기

- 날짜: 2026-11-19
- 주소: www.cbiseo.com/m/quote (청소비서 메인 「모바일 CRM」 버튼)
- 대상: CRM을 쓰는 업체의 관리자·마케터 (CRM을 안 쓰는 업체에는 버튼이 보이지 않음)

## 무엇이 바뀌었나
- 이름: 「견적 도우미」 → 「모바일 CRM」.
- 메인 버튼: PC는 위쪽 메뉴 줄 오른쪽, 휴대폰은 대시보드 카드. 누르면 다시 로그인 없이 바로 열림.
- 내 문구: CRM 숨고 문구(공용·개인)를 검색해서 한 줄씩 촘촘히 보고, 「복사」 한 번으로 붙여넣기. 여러 개짜리 문구는 1/2, 2/2 차례로 복사.
- 즐겨찾기·개인·공용·최근 쓴 칩으로 좁히기, 「+ 새 문구」로 추가, 수정·삭제는 CRM 문구에도 그대로 반영.

## 홍보 문구 예시
자주 쓰는 숨고 문구, 검색 한 번·복사 한 번. 현장에서도 휴대폰으로 바로.
