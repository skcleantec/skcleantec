# 플랫폼 업체관리 기능 탭 정리

- 무엇이 바뀌었나: 플랫폼 업체관리 → 업체 상세의 기능 탭을 정리했습니다. 기능마다 켜짐·꺼짐 스위치 하나만 두고, 기능을 용도별 6묶음(기본 기능, 접수·업무, 고객 연락·결제, 현장·팀, 정산·계약, 업체 전용)으로 나눴습니다. 기능 이름 아래에 켜면 업체 화면에 생기는 메뉴를 적었습니다.
- 누가 쓰나: 플랫폼 운영자
- 어디서 쓰나: 플랫폼 → 업체 목록 → 관리 → 기능
- 이전과 차이: 「기본 따름 / 켜기 / 끄기」 선택과 「최종·이유」 칸, 아래쪽 「화면 표시 설정」이 하나로 합쳐졌습니다. 플랜과 다르게 설정한 기능에만 「플랜 외 · 따로 켬」, 「플랜 포함 · 따로 끔」 표시와 「기본값으로」가 붙습니다. 바꾼 기능에는 「저장 전」이 붙고 아래에 「되돌리기 / 저장」 바가 뜹니다. 메뉴와 기능의 연결은 「메뉴별로 보기」를 열어 확인합니다.
