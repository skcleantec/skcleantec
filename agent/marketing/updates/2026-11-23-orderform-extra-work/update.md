# 발주서 — 추가 시공을 이름·금액으로 넣기

- 날짜: 2026-11-23
- 위치: 서비스접수 「발주서 발급」의 발급 금액 / 고객 발주서 첫 화면
- 대상: 관리자·마케터, 발주서를 받는 고객

## 무엇이 바뀌었나
- 발급 금액에서 「+ 추가 시공 넣기」를 누르면 인테리어 청소·특수청소 같은 추가 시공을 이름과 금액으로 여러 줄 넣을 수 있음.
- 넣으면 「총 금액」이 「기본 청소 금액」으로 바뀌고, 기본 + 추가 시공 합계가 총 견적으로 자동 계산됨. 잔금도 자동.
- 고객이 발주서를 열면 첫 화면에서 청소를 고르는 대신 「예약하신 청소를 확인해 주세요」 카드로 기본 청소와 함께 받는 추가 시공, 총 견적·예약금·잔금을 한눈에 봄.
- 발주서 목록, 고객 제출 내역, 접수 확인 메일, 팀장 배정 상세에도 추가 시공이 같이 나옴.
- 추가 시공을 넣지 않으면 발급·고객 화면 모두 지금과 같음.

## 홍보 문구 예시
입주청소에 인테리어 청소까지, 한 장의 발주서로. 고객은 무엇을 함께 받는지 첫 화면에서 바로 확인해요.

## 화면
- 캡처 없음. 필요하면 테스트 업체로 다시 찍을 것.
