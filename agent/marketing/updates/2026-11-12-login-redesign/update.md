# 로그인 화면 새 디자인

- 무엇이 바뀌었나: 로그인 화면을 새로 꾸몄습니다. PC에서는 왼쪽에 청소비서 실제 화면(대시보드·스케줄·텔레CRM)이 5초마다 넘어가고, 오른쪽에 로그인 카드가 있습니다. 모바일은 위쪽 남색 영역 아래로 로그인 카드가 올라옵니다.
- 누가 쓰나: 업체 관리자·마케터·팀장·팀원 모두.
- 어디서 쓰나: cbiseo.com/login
- 이전과 차이: 「팀원계정로그인」 스위치가 「업체 계정 | 팀원 계정」 탭으로 바뀌었습니다. 회원가입은 오른쪽 위(모바일은 맨 위) 「처음이신가요? 회원가입」으로 옮겼습니다. 카드 위에 최신 공지 한 줄(새 소식)이, 카드 아래에 도움말·교육 신청·도입 문의 링크가 생겼습니다. 로그인 방법(업체 코드·아이디·비밀번호, Google·카카오)은 그대로입니다.
