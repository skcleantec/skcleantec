# 숨고 연동 2.2.60 — 메시지 전송 오류 수정

- 날짜: 2026-11-23
- 위치: 텔레CRM 「숨고 메시지」 / PC의 「청소비서 숨고 연동」 프로그램
- 대상: 숨고 연동을 쓰는 마케터

## 무엇이 바뀌었나
- 메시지를 보낸 직후 숨고 화면이 바뀌면 영어 오류가 길게 뜨던 문제를 고침.
- 보낸 뒤 성공인지 확인이 안 될 때는 자동으로 다시 보내지 않고 「숨고 채팅방에서 확인한 뒤 다시 보내 주세요」라고 안내함(같은 메시지가 두 번 가는 것을 막음).
- 프로그램은 다음 실행 때 2.2.60으로 자동 업데이트됨.

## 홍보 문구 예시
숨고 메시지, 오류 없이 한 번만 정확히 보냅니다.
