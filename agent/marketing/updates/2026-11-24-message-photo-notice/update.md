# 메시지 공지에 사진 묶음·PDF 보내기

- 날짜: 2026-11-24
- 위치: 메시지 (관리자·마케터) / 팀장 메시지 / 팀원 공지
- 대상: 관리자·마케터가 보내고, 팀장·외부업체·팀원이 받음

## 무엇이 바뀌었나
- 「현장 공지(일괄 발송)」와 1:1 대화에 사진 여러 장(한 번에 30장)과 PDF를 붙여 보낼 수 있음. 글 없이 사진만 보내도 됨.
- 사진은 카카오톡처럼 한 묶음으로 보이고, 누르면 원본으로 크게 열려 확대해도 글씨가 깨지지 않음. 한 장 또는 묶음 전체를 저장.
- PC에서는 폴더에서 끌어다 놓거나 복사한 그림을 붙여넣어도 됨. 번호가 보내지는 순서이고 바꿀 수 있음.
- 공지를 보내기 전에 받는 사람과 장수를 한 번 확인.
- 공지는 단체방이 아니라 받는 사람마다 따로 감. 팀장끼리는 서로 메시지를 주고받을 수 없음.
- 공지 말풍선 옆 「읽음 9/13」을 누르면 누가 읽었고 누가 안 읽었는지 보임. 사진·파일이 붙은 공지는 한 번 눌러 봐야 읽음으로 침.
- 안 읽은 사람에게만 알림을 한 번 더 보낼 수 있음(같은 공지는 1시간에 한 번).
- 「공지 모아보기」: 관리자·마케터는 보낸 공지와 읽음 현황을 표로, 팀장은 받은 공지의 사진·파일을 날짜별로 다시 찾음.
- 지난 공지의 사진·파일을 새 공지에 다시 붙일 수 있음(새 팀장에게 교육자료 다시 보낼 때).
- 팀원은 그룹이 같은 계정을 써서 읽음이 그룹별로 보임.
