# 플랫폼 업체관리 요금 탭 정리 · 이용료 면제 범위

- 무엇이 바뀌었나: 플랫폼 업체관리 → 업체 상세의 요금·청구 탭을 정리했습니다. 맨 위에 월 이용료·부가 요금·다음 청구·지갑 잔액 요약이 생겼고, 플랜 카드와 계약 조건이 「계약」 카드 하나로 합쳐졌습니다. 이용료를 「표준 / 약정 / 면제」 중에서 고르고, 면제 업체는 부가 요금(랜딩 문의 링크)까지 면제할지 직접 정합니다.
- 누가 쓰나: 플랫폼 운영자
- 어디서 쓰나: 플랫폼 → 업체 목록 → 관리 → 요금·청구
- 이전과 차이: 「약정 0원」으로 면제를 대신하던 방식 대신 「면제」 버튼이 생겼습니다. 면제 업체는 업체 목록과 청구 일정 모든 회차에 「면제」로 표시됩니다. 청구 일정은 이용료와 부가 요금을 나눠 보여 주고, 줄마다 「입금완료」와 「···」 메뉴만 남겼습니다. 무효 청구서는 「무효 청구서 보기」를 켤 때만 보입니다. 플랜 사용량 표는 개요 탭으로 옮겼습니다.
