# 고정 입금처 — PG사·협력업체 입금은 알림 없이 쌓기

- 날짜: 2026-11-26
- 위치: 관리자 › 서비스접수 › 입금 확인 › 「폰·통장·알림 설정」 › 고정 입금처 탭, 입금내역 줄의 「고정 입금처」 버튼
- 대상: 관리자·마케터

## 무엇이 바뀌었나
- 카드 결제 정산(PG사)이나 협력업체처럼 늘 들어오는 입금자를 「고정 입금처」로 등록해 두면, 그 이름으로 입금이 와도 화면 알림·휴대폰 알림·팀장 확인 요청이 가지 않음.
- 등록은 두 곳에서: 입금내역의 「확인 필요」 줄 끝 「고정 입금처」 버튼(이름이 자동으로 채워짐), 또는 설정 창의 고정 입금처 탭 「+ 추가」.
- 등록 창에서 표시명·구분(PG사·협력업체·기타)·브랜드(모든 브랜드 또는 특정 브랜드)·메모를 적고, 「뒷자리 숫자·기호가 달라도 같은 입금처로 보기」를 켜면 KSNET_1234 처럼 번호가 바뀌어도 같은 곳으로 봄.
- 등록할 때 아직 확인 안 한 같은 이름 입금이 있으면 함께 「고정 입금처」로 접을 수 있음.
- 목록에서 알림을 잠깐 끄고 켜거나(토글), ⋯ 메뉴로 수정·지우기 가능. 수정·지우기는 관리자만.
- 입금 기록은 사라지지 않음. 입금내역의 「청소와 무관」 묶음에 「고정 입금처 · 이름」으로 남고, 「되돌리기」로 보통 입금처럼 되돌릴 수 있음.

## 이전과 차이
- 전에는 PG사 정산이 들어올 때마다 알림이 울리고 「확인 필요」에 쌓여 매번 「청소와 무관」을 눌러야 했음. 이제 한 번 등록하면 조용히 쌓임.
