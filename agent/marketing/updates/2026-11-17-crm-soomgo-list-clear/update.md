# 텔레CRM · 숨고 목록으로 나오면 접수란 비우기

- 무엇이 바뀌었나: 숨고 창이 채팅방에서 목록으로 바뀌면, 접수란에 적어 둔 내용을 비웁니다. 비우기 전에 화면 가운데 「숨고 채팅 목록으로 나와서 접수란을 비웠어요.」가 뜨고, 「이전 입력 복구」로 10분 동안 되돌릴 수 있습니다.
- 누가 쓰나: 텔레CRM으로 상담하는 직원.
- 어디서 쓰나: 텔레CRM 접수란. 컴퓨터 창과 팝업 창이 같습니다.
- 이전과 차이: 숨고에서 가져온 내용만 비우지 않습니다. 직접 입력·부재·보류·빠른일정·고객 조회도, 채팅방에서 목록으로 나오면 비웁니다. 처음부터 목록에 있는 상태에서 입력 중인 내용은 그대로 둡니다.
