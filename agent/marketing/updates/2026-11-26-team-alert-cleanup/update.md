# 팀장 알림 겹침 정리

- 날짜: 2026-11-26
- 위치: 팀장 앱 알림, 관리자 › 알림 설정
- 대상: 팀장·관리자

## 무엇이 바뀌었나
- 해피콜 알림은 작업 전날 저녁 6시부터 자정까지만, 「해피콜 완료」를 누를 때까지 약 1시간마다 감. 작업 당일에는 더 이상 가지 않음(완료하지 않은 건은 화면에 미완료로 계속 표시).
- 같은 접수의 해피콜 알림, 같은 입금 건의 확인 재알림은 휴대폰 알림창에 한 줄로만 남음(새 알림이 앞의 것을 덮음).
- 팀장 본인이 바꾼 내용(예약일, 미팅 시간 등)은 본인 휴대폰으로 알림이 가지 않음.
- 관리자가 팀장을 배정하면서 다른 내용도 함께 저장하면, 새로 배정된 팀장에게는 「배정」 알림 하나만 감.
- 관리자 알림 설정의 해피콜 칸은 보내는 때 안내로 바뀜(반복 간격·횟수 입력 없음).
