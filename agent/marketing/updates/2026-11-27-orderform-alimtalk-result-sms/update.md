# 발주서 알림톡 결과 팝업 · 문자로 보내기

- 날짜: 2026-11-27
- 위치: 서비스접수 › 발주서 발급, 발주서 목록
- 대상: 관리자·마케터

## 무엇이 바뀌었나
- 「알림톡 발송」을 누르면 화면 가운데에 성공("알림톡을 보냈어요") 또는 실패("알림톡을 보내지 못했어요")와 이유가 뜸.
- 알림톡이 안 되면 그 자리에서 「문자로 보내기」를 누를 수 있음. 받는 번호·문자 종류·비용(긴 문자 1건 60원, 무료 건수면 3건)을 먼저 보여 줌.
- 발급 완료 화면의 「알림톡 발송」 옆, 발주서 목록 「설정」 창에 「문자로 보내기」 버튼이 생김. 문자 내용과 비용을 확인한 뒤 보냄.
- 발급 완료 화면 아래와 발주서 목록에 발송 상태가 표시됨: 도착 확인 중 / 알림톡 도착 / 알림톡 실패 / 문자 발송됨.
- 알림톡이 접수된 뒤 고객에게 전달되지 않았을 때 문자가 자동으로 대신 나가는 것은 전과 같음.
