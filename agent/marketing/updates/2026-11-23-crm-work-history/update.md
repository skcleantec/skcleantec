# CRM — 작업 기록 (저장 안 한 고객을 다시 찾기)

- 날짜: 2026-11-23
- 위치: 텔레CRM 왼쪽 도구 메뉴 「작업 기록」 / 접수란 위 알림
- 대상: CRM을 쓰는 관리자·마케터 (PC CRM)

## 무엇이 바뀌었나
- 접수란에 올린 고객마다 기록이 남음: 어디서 불러왔는지, 통화·견적·문자·메시지, 직접 고친 내용, 저장했는지 넘어갔는지.
- 저장하지 않고 다른 고객으로 넘어가거나 접수란을 비우면 「○○님을 저장하지 않았어요」가 뜨고 「되돌리기」로 적던 내용을 되살림. 막지는 않음.
- 왼쪽 메뉴 「작업 기록」에 저장 안 한 고객 수가 빨간 숫자로 보임. 창에서 「이어서 하기」로 그때 적던 내용을 접수란에 되살리거나 「필요 없음」으로 정리.
- 불러오기만 하고 아무것도 안 한 고객은 「보기만 함」으로 따로 남고 숫자에 세지 않음.
- 마케터는 본인 기록만, 관리자는 마케터별 「불러옴 / 저장 / 저장 안 함 / 보기만」 숫자와 기록을 봄.
- 아래쪽 목록의 줄마다 「다시 불러오기」가 있어, 보기만 하고 넘어간 고객도 접수란에 되살림.
- 신규에서 채운 내용은 「기존」 탭을 눌렀다가 돌아와도 그대로 남음(기존에서 다른 고객을 불러오지 않았을 때).
- 기록은 30일, 저장 안 한 고객의 적던 내용은 14일 뒤 자동으로 지워짐.
- 「이전 입력 복구」로 되살린 내용이 기존 고객 조회에 덮어써지던 문제도 함께 고침.

## 홍보 문구 예시
바쁘게 상담하다 저장을 놓쳐도 괜찮아요. 누구를 하다 말았는지 CRM이 기억하고 그대로 되살려 줍니다.
