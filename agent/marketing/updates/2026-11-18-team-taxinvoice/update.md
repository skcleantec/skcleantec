# 팀장도 세금계산서까지, 발행한 영수증은 원본으로 바로 확인

- 날짜: 2026-11-18
- 대상: 팀장 앱 「영수증」 메뉴 · 배정 상세 · 관리자 현금영수증 설정

## 무엇이 바뀌었나
- 팀장 메뉴 「현금영수증」이 「영수증」으로 바뀌고, 위쪽 탭에서 현금영수증·세금계산서를 골라요.
- 팀장도 세금계산서를 발행해요: 사업자번호(저장된 거래처 자동 불러오기), 상호, 대표자, 받을 이메일, 합계 금액(공급가액·세액 자동), 품목, 영수/청구. 발행하면 받는 곳 이메일로 자동 발송. 1건 150원.
- 현금영수증에 과세·면세 선택이 생겼어요. 팀장 화면 기본값은 관리자 현금영수증 설정 「팀장 발행 기본 과세구분」에서 정해요(면세사업자는 면세 고정).
- 내역마다 「영수증 보기」로 국세청 발행 원본을 바로 열고, 「문자 보내기」로 고객에게 영수증 링크를 보내요.
- 수정·취소는 「사무실에 요청」. 공동인증서가 없으면 「사무실에 등록 요청」.

## 홍보 문구 예시
사업자 고객이 세금계산서를 달라고 해도 현장에서 바로. 팀장 휴대폰 하나로 현금영수증·세금계산서 끝.
