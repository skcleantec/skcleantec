# 세금계산서 · 목록 먼저, 발행은 실제 양식 페이지에서

- 무엇이 바뀌었나: 세금계산서 메뉴를 열면 발행 목록이 먼저 나오고, 오른쪽 위 「+ 세금계산서 발행」을 누르면 발행 전용 화면으로 넘어갑니다. 발행은 지금처럼 실제 세금계산서 양식 칸에 바로 적습니다.
- 누가 쓰나: 세금계산서를 발행하는 업체 관리자와 마케터.
- 어디서 쓰나: 서비스접수 → 영수증 → 세금계산서, 접수 상세의 「세금계산서 발행」.
- 이전과 차이: 「발행하기/발행 내역」 탭이 없어지고, 양식 위 한 줄에서 거래처 검색·접수 연결·과세 구분을 고릅니다. 화면 아래에 합계와 발행 버튼이 늘 보이고, 발행하면 목록으로 돌아가 방금 낸 건이 초록으로 표시됩니다.
