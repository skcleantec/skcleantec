# 부재·보류 — 안심번호 48시간 초과 표시

- 날짜: 2026-11-23
- 위치: 서비스접수 「부재·보류」 목록 / 텔레CRM 「부재보류」
- 대상: 관리자·마케터

## 무엇이 바뀌었나
- 0504 안심번호가 저장된 고객은 연락처 아래에 표시가 붙음. 등록하고 48시간 전에는 「안심 N시간 남음」, 지나면 빨간 「48시간 초과」.
- 48시간이 지난 안심번호만 있는 고객은 「전화」가 걸리지 않음(번호가 끊겼거나 다른 사람에게 넘어갔을 수 있어서). 고객 연락처가 같이 있으면 그 번호로 그대로 걸림.
- 48시간은 부재·보류 등록일부터 셈.

## 홍보 문구 예시
끊긴 안심번호로 엉뚱한 사람에게 전화하는 일, 이제 목록에서 미리 알려 드려요.
