# 전자계약 체결 화면 5단계 · 사진 별도 제출 · 갑 도장

- 날짜: 2026-11-27
- 위치: 전자계약 체결 화면(팀장·마케터·팀원이 받는 계약 링크), 전자계약 › 체결 내역
- 대상: 계약서를 받는 팀장·마케터·팀원, 관리자

## 무엇이 바뀌었나
- 체결 화면이 5단계로 나뉨: 계약서 읽기 → 체결 정보 입력 → 서명 → 본인 확인 → 확인하고 제출. PC도 같은 화면.
- 계약서를 끝까지 내려야 다음 단계로 넘어감. 본문 글자 크기와 줄바꿈을 휴대폰에서 읽기 좋게 맞춤.
- 체결 정보는 한 화면에서 위에서 아래로 입력. 빠진 칸이 있으면 그 칸으로 이동해 알려 줌.
- 본인 확인 단계에서 「사진 제출하기」를 누르면 찍는 방법 예시가 먼저 나옴.
- 「사진은 따로 제출하겠습니다」에 직접 체크하면 사진 없이 제출 가능. 관리자 체결 내역에 「셀카 미제출」로 표시되고, 관리자가 나중에 사진을 올릴 수 있음. 계약서에는 「사진 별도 제출」로 기록됨.
- 계약서 끝 갑 칸이 「대표자 이름 (인)」 한 줄로 바뀌고, 업체 정보에 등록한 직인이 (인) 자리에 찍힘. 새로 발급·체결하는 계약서부터 적용.
- 체결된 계약서 화면에서 을 서명이 깨져 보이던 것을 고치고, 서명 칸 안에 들어가게 맞춤.
