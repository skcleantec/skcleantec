# 입금 확인 — 통장 입금 문자를 접수와 실시간으로 맞추기

- 날짜: 2026-11-24
- 위치: 서비스접수 › 입금 확인 / 접수 상세 / PC CRM 알림
- 대상: 관리자·마케터 (「입금 확인」 기능을 켠 업체만)

## 무엇이 바뀌었나
- 사업자폰에 「청소비서 입금 알림」 앱을 깔아 두면 은행 입금 문자가 오는 즉시 「입금 확인」 목록에 올라오고 화면 오른쪽 아래에 알림이 뜸.
- 입금자명이 고객명·닉네임과 같고 금액이 계약금·잔금·총액 중 하나와 같은 접수가 딱 한 건이면 자동으로 연결. 나머지는 「확인 필요」로 남아 「고객 찾기」 창에서 직접 고름.
- 이미 계약금·잔금이 들어온 접수에 총액이 또 들어오는 식의 겹침은 자동으로 잇지 않음.
- 접수 상세에 「✓ 계약금 20,000원 입금 확인」 줄이 붙음. 접수 상태는 저절로 바뀌지 않음.
- 통장 잔액은 폰에서 지우고 보내 서버에 저장하지 않음.
- 알림에 브랜드·고객명·담당 마케터가 함께 나오고, 목록에는 「담당 · 팀장」 칸이 있어 누구 고객의 입금인지 바로 보임. 알림은 관리자·마케터 모두에게 뜸.
- 발주서가 들어오면 계약금 입금을 다시 맞춤.
- 담당 팀장이 있는 접수에 잔금이 들어오면 그 팀장에게 모바일 알림과 화면 팝업.
- 주인을 못 찾은 잔금은 모든 팀장에게 알리고(10분마다), 팀장이 자기 배정 접수를 골라 확인. 금액이 다르면 이유를 고르고 한 번 더 확인.
- 팀장이 접수 상세에서 「회사 계좌로 입금받기」로 입금자명을 적어 두면 입금되는 순간 자동 확인.
- 폰이 문자함을 다시 훑어 빠진 입금 문자를 가져옴(「뒤늦게 가져옴」 표시). 읽지 못한 문자는 화면에 따로 보여 줌.
- 「입금 직접 추가」로 문자로 못 받은 입금을 손으로 넣을 수 있고, 관리자는 잘못 들어온 줄을 한 건씩 지울 수 있음.
- 「폰·통장·알림 설정」에서 팀장 알림 켜고 끄기, 얼마 미만은 팀장에게 묻지 않기, 다시 알리는 간격·시간대·기간, 계약금으로 보는 금액, 사무실 화면 알림을 정함.
- 입금 확인에 「예약취소」 단추와 상태가 생기고, 접수를 예약취소하면 연결된 입금도 함께 예약취소로 바뀜.
- 목록 필터: 기간(하루씩·최근 7일·최근 30일·이번 달)·브랜드·종류·상태. 마지막에 쓰던 필터를 기억함.
- 휴무인 팀장에게는 주인 없는 입금을 묻지 않음.
- 팀장 앱: 주인 없는 입금이 화면 가운데 창으로 뜨고 답해야 다른 화면을 씀. 접수 상세에 「계좌입금」 단추 — 안내 계좌 복사, 금액·입금자명 적고 기다리면 입금되는 순간 자동 확인.
- 관리자 전용 › 사업자 정보에 브랜드별 「입금 안내 계좌」 칸.
- 청소비서 앱 알림: 입금이 들어오면 관리자·마케터 전원의 폰에 한 번 알림(「입금 20,000원 · 입금자」). 누르면 입금 확인 화면으로 이동. 관리자 전용 › 알림설정의 「입금 알림」에서 켜고 끄고, 각자 본인 알림 설정에서 끌 수 있음.
- 사업자폰이 입금 알림을 못 듣거나(권한 꺼짐·앱 멈춤·연결 끊김) 하면 입금 확인 화면 위에 경고가 뜨고 관리자 폰으로 알림(같은 문제는 1시간에 한 번). 설정 창의 폰 줄에 앱 버전과 「알림 듣는 중」 여부가 보임.
- 사업자폰이 12분 넘게 조용하면 화면을 열지 않아도 관리자 폰으로 알림이 가고, 다시 연결되면 「다시 연결됐어요」 알림. 폰이 멈춰 있다 늦게 올라온 입금에는 「○시간 늦게 들어옴」 표시.
- 관리자는 「폰·통장 설정」에서 6자리 코드로 폰을 연결하고 통장을 브랜드에 등록. 폰이 20분 넘게 연결되지 않으면 화면에 표시.
