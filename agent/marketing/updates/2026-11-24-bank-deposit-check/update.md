# 입금 확인 — 통장 입금 문자를 접수와 실시간으로 맞추기

- 날짜: 2026-11-24
- 위치: 서비스접수 › 입금 확인 / 접수 상세 / PC CRM 알림
- 대상: 관리자·마케터 (「입금 확인」 기능을 켠 업체만)

## 무엇이 바뀌었나
- 사업자폰에 「청소비서 입금 알림」 앱을 깔아 두면 은행 입금 문자가 오는 즉시 「입금 확인」 목록에 올라오고 화면 오른쪽 아래에 알림이 뜸.
- 입금자명이 고객명·닉네임과 같고 금액이 계약금·잔금·총액 중 하나와 같은 접수가 딱 한 건이면 자동으로 연결. 나머지는 「확인 필요」로 남아 「고객 찾기」 창에서 직접 고름.
- 이미 계약금·잔금이 들어온 접수에 총액이 또 들어오는 식의 겹침은 자동으로 잇지 않음.
- 접수 상세에 「✓ 계약금 20,000원 입금 확인」 줄이 붙음. 접수 상태는 저절로 바뀌지 않음.
- 통장 잔액은 폰에서 지우고 보내 서버에 저장하지 않음.
- 관리자는 「폰·통장 설정」에서 6자리 코드로 폰을 연결하고 통장을 브랜드에 등록. 폰이 20분 넘게 연결되지 않으면 화면에 표시.
