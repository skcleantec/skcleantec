# CRM PC — 공유 메모를 텔레CRM에서 바로 보기

- 날짜: 2026-11-22
- 위치: 텔레CRM(PC) 왼쪽 「도구」 메뉴
- 대상: CRM을 쓰는 업체의 관리자·마케터 (모바일 CRM에는 없음)

## 무엇이 바뀌었나
- 스케줄 화면의 「공유 메모」를 텔레CRM에서도 봄. 도구 메뉴를 펼치면 단추 아래에 노란 쪽지로 바로 보임.
- 메모가 바뀌면 「공유 메모」 단추에 빨간 숫자, 쪽지에 빨간 점이 뜸.
- 쪽지나 단추를 누르면 큰 창이 열림. 고칠 수 있는 계정은 여기서 바로 고침(스케줄 화면과 같은 권한).
- 「위에 한 줄로 고정」을 켜면 화면 맨 위에 한 줄 띠로 남아 통화 중에도 보임.

## 홍보 문구 예시
오늘 지침, 스케줄 화면까지 안 가도 돼요. 상담 화면 옆에 쪽지로 붙어 있어요.

## 화면
- 캡처 없음(메모에 내부 일정이 있어 생략). 필요하면 테스트 업체로 다시 찍을 것.
