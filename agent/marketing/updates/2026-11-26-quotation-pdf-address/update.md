# 견적서 PDF 주소 겹침 정리 · 저장 확인 줄이기

- 날짜: 2026-11-26
- 위치: 관리자·팀장 › 견적서 작성 › PDF 보기·메일 보내기
- 대상: 관리자·마케터·팀장

## 무엇이 바뀌었나
- 견적서 PDF의 공급자·공급받는자 칸에서 주소가 길어 두 줄로 접히면, 아래 전화·이메일 줄과 겹치던 것이 고쳐짐(칸 높이가 내용에 맞게 늘어남).
- 견적서를 저장한 뒤 내용을 바꾸지 않았으면 PDF 보기·메일 보내기 전에 「저장할까요?」를 다시 묻지 않음. 바꾼 게 있을 때만 물음.

## 이전과 차이
- 전에는 긴 주소에서 글자가 겹쳐 PDF를 다시 뽑아야 했고, 저장 직후에도 매번 저장 확인이 떴음.
