# 플랫폼 카드결제 PG 가맹점 진행 현황

- 무엇이 바뀌었나: 플랫폼 「카드결제 PG > PG 연동」 맨 위에 가맹점 진행 현황이 생겼습니다. 모든 업체를 미신청 / 작성 중 / 신청 접수 / PG 심사 중 / 계약 대기 / 계약 완료 / 반려로 나누고, 업체마다 신청 → PG 전달 → 개통 → 전자계약 → 결제 키를 날짜와 함께 보여 줍니다.
- 누가 쓰나: 플랫폼 운영자
- 어디서 쓰나: 플랫폼 → 카드결제 PG → PG 연동
- 이전과 차이: 「가입 신청」 목록은 상태 한 줄만 보여 주고 모든 업체에 「PG 전달」 버튼이 떠 있었습니다. 이제 신청서를 열어 보기만 하고 입력하지 않은 업체는 「미신청」으로 보이고, 단계에 맞는 버튼(PG 전달, 개통 처리·반려)만 보입니다. 처리할 일이 있는 업체가 위에 옵니다.
- 함께 바뀐 것: 아래에 길게 이어지던 원성 로그인 주소·수수료·이용료 결제·업체 결제 키 섹션을 작은 버튼 4개(업체 결제 키 / 수수료 / 원성 로그인 주소 / 이용료 결제 테스트)로 줄였습니다. 누르면 가운데 창이 열려 기존과 같은 내용을 씁니다.
