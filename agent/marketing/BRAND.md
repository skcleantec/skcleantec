# 청소비서 브랜드 키트 (마케팅용)

갱신일: 2026-09-15

## 제품이 무엇인지 (한 줄)

**청소비서**는 입주·이사 청소 업체가 **접수 → 일정 → 현장 팀 → 정산**을 한곳에서 다루는 업무 앱입니다.  
고객(집주인)이 쓰는 공개 링크(발주서·전자계약 등)와, 업체 직원이 쓰는 관리·팀장 화면이 있습니다.

## 이름

| 써도 됨 | 쓰지 말 것 |
|---------|------------|
| 청소비서 | SK클린텍, SKCleantec, skcleantec (제품명처럼) |
| CBISEO, Cbiseo | 「SK클린텍 프로젝트」 |
| 운영 사이트 예: cbiseo.com | 저장소 폴더 이름을 브랜드로 소개 |

개별 청소 업체의 상호는 **그 업체의 이름**입니다. 청소비서는 **여러 업체가 쓰는 플랫폼**입니다.

## 브랜드 색 (화면에서 실제로 쓰는 기준)

Tailwind 기본값입니다. 배너·포스터에도 **이 hex**를 쓰세요.

| 역할 | 토큰 | hex | 쓰는 곳 |
|------|------|-----|---------|
| 주요 버튼·선택됨 | slate-900 | `#0f172a` | 저장, 로그인 제출, 기간 버튼 선택 |
| 주요 버튼 호버 | slate-800 | `#1e293b` | 버튼에 마우스 올렸을 때 |
| 본문 배경 | slate-100 | `#f1f5f9` | 카드 바깥 바탕 (가이드 문서상 `#f4f6f8`과 가까운 회색) |
| 카드 | white | `#ffffff` | 목록·상세 흰 상자 |
| 본문 글자 | slate-700 | `#334155` | 설명 문장 |
| 위쪽 어두운 메뉴(선택됨) | blue-600 | `#2563eb` | 관리·팀장 상단에서 **지금 있는 메뉴** |
| 입력칸 포커스 | sky-500 | `#0ea5e9` | 로그인 등 칸을 눌렀을 때 |
| 잘됨·완료 계열 | emerald-600 | `#059669` | 성공, 종일 일정 띠 |
| 주의·오전·대기 | amber-500 | `#f59e0b` | 경고, 오전 일정 띠 |
| 오후·정보 | sky-600 | `#0284c7` | 오후 일정 띠 |
| 위험·미제출·처리 전 | rose-500 / red-500 | `#f43f5e` / `#ef4444` | 아직 안 끝난 일, 빨간 테두리 |
| 사이·정보공유 구역 | violet-500 | `#8b5cf6` | 사이청소·시간 미확정 |

**마케팅에서 하지 말 것:** 주요 버튼을 파란색(`#2563eb`)으로 그리기. 앱에서는 파란 것은 **위 메뉴 선택**이고, 큰 버튼은 **거의 검정(`#0f172a`)** 입니다.

## 말투

- 짧고 일 잘하는 느낌. 「혁신적인 솔루션」 같은 빈말 금지.
- 현장 말로: 접수, 배정, 오전/오후, 잔금, 해피콜.
- 영어 약자(API, DB, GNB) 없이 설명.

## 누가 어떤 화면을 쓰나

| 사람 | 들어가는 곳 | 상단 메뉴 예 |
|------|-------------|--------------|
| 관리자·마케터 | 로그인 후 관리 화면 | 대시보드, 서비스접수, 스케쥴, 정보공유, 광고비, 메시지 (+ 관리자만 「관리자 전용」) |
| 현장 팀장 | 로그인 후 팀 화면 | 대시보드, 배정목록, 스케줄, 정산, 가계부, 정보공유, 휴무일, C/S, 메시지 |
| 청소비서 운영팀 | 플랫폼 화면 | 업체 관리, 결제 관리 등 (업체 직원이 평소에 안 봄) |
