# 관리자 전용

갱신일: **2026-09-28**

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 왼쪽에서 선택

관리자만 보입니다. 각 화면 **메뉴 제목 옆 ?**, 등록·수정 창 **제목 옆 ?** 로 그 화면만 쉬운 설명이 나옵니다.

## 사용자 등록

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「사용자 등록」 → 사람 선택 → 「상세·수정」

- 팀장·마케터·사무 계정을 만들고 고칩니다.
- 「사원증 사진」을 올리면 손님이 볼 인증 사진으로 씁니다.

## PG신청

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「업체등록정보」 → 「PG신청」

화면 제목은 **PG신청**입니다. 연결 전에는 안내 이미지와 **미연결·심사중·반려**, **신청서 · 심사 · 연결**, **PG 신청하기**가 있습니다. 연결되면 안내 대신 **연결됨**과 결제 표(결제일, 팀장, 고객, 접수번호, 방식, 상태, 결제액, 수수료, 실수령)가 나옵니다. 상태는 결재완료·취소·실패 등이고, 방식은 수기결재·고객링크결재입니다. 원성 로그인 주소는 이 화면에 없습니다.

- **PG 신청하기**를 누르면 신청서가 열립니다.
- 상호, 사업자번호, 대표자, 담당 연락처, 정산 계좌를 적고 「PG 신청 제출」을 누릅니다.
- 청소비서에 사업자등록증이 있으면 그 파일이 전달됩니다. 없으면 이미지를 올려야 제출할 수 있습니다.
- 페이지 맨 위에는 **원성페이먼츠 PG 연동** 안내 이미지가 있습니다.
- 카드번호는 받지 않습니다.

|----------------|----------------|-----------|--------------|--------|
| 미연결 | 아직 신청하지 않음 | amber-50 / amber-900 | #fffbeb / #78350f | 없음 |
| 심사중 | 제출한 신청을 확인 중 | slate-50 / slate-800 | #f8fafc / #1e293b | 없음 |
| 연결됨 | 카드 결제가 연결됨 | emerald-50 / emerald-800 | #ecfdf5 / #065f46 | 없음 |
| 반려 | 다시 신청할 수 있음 | red-50 / red-800 | #fef2f2 / #991b1b | 없음 |
| 카드 결제 · 원성페이먼츠 PG | 위쪽 안내 띠 | slate-900 | #0f172a | 없음 |
| 신청서 · 심사 · 연결 | 진행 단계. 지금 단계는 진한 원, 지난 단계는 초록 | slate-900 / emerald-600 | #0f172a / #059669 | 없음 |
| PG 신청하기 | 신청서를 염 | slate-900 | #0f172a | 없음 |
| PG 신청 제출 | 신청을 보냄 | slate-900 | #0f172a | 없음 |

## PG 연동

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「PG 연동」

PG가 연결된 뒤에 보입니다. 판매자센터 주소·아이디·비밀번호가 적혀 있습니다.

- **원성페이접속**을 누르면 새 창이 열리고, 적어 둔 아이디와 비밀번호로 원성페이먼츠 판매자센터에 로그인됩니다. 관리자 전용 메뉴를 쓰는 마케터도 같은 버튼과 결제 내역 취소·삭제를 씁니다.

| 원성페이접속 | 판매자센터를 새 창에서 연다 | slate-900 | #0f172a | 없음 |

## 플랜에 없는 메뉴

**클릭 경로:** 로그인 → 상단 메뉴 이름 옆 자물쇠 → **업그레이드 보기**

- 지금 요금제에 없는 상위 메뉴는 상단에 남고, 하위 메뉴 잠금은 왼쪽 메뉴에만 있습니다.
- 업체가 끈 기능은 잠금으로 보이지 않고 메뉴에서 빠집니다.

## 1인 업체 가계부

**클릭 경로:** 로그인(1인 업체 관리자) → 상단 「가계부」 또는 휴대폰 하단 「가계부」

- 사장 본인의 수입·지출입니다. 팀장 가계부 조회 화면이 아닙니다.
- 월 합계 아래 날짜별 내역이 있고, 접수와 연결된 줄이 있습니다.
- 버튼 **수입/지출 추가**는 slate-900 `#0f172a` 흰 글자입니다. **내 접수 불러오기**와 **설정**은 흰 배경에 slate-800 `#1e293b` 글자입니다.

## 계산서 연결

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「계산서 연결」

- 영업브랜드마다 카드가 있습니다. 이름 옆에 **기본 브랜드** 또는 **추가 브랜드**, 상태 칩, 사업자번호(`229-**-*****`처럼 앞 세 자리만)가 있습니다.
- **미연결:** 「현금영수증·세금계산서를 발행하려면 바로빌 연결이 한 번 필요해요.」 상호·대표자·주소와 **사업자정보 수정**, 업태·종목·담당 전화·담당 이메일, 「업태·종목은 사업자등록증에 적힌 대로 넣어 주세요.」, **바로빌 연결하기**.
- **연결 요청 필요:** 「이미 바로빌을 쓰고 있는 사업자예요」. **바로빌 아이디**는 필수입니다. 모르면 바로빌 홈페이지 아이디 찾기, 안 되면 대표자가 바로빌 고객센터 1544-9256. 그다음 **연결 요청하기**. 거절된 뒤에는 사유와 **다시 요청하기**.
- **연결 처리 중:** 「연결 요청을 보냈어요」와 4단계(연결 요청, 청소비서 연결 처리, 공동인증서 등록, 발행 시작). **요청 취소**.
- **연결됨:** 현금영수증 발행 가능, 세금계산서는 인증서가 필요. **공동인증서 등록**, **현금영수증 발행하러 가기**.
- **사용 가능:** 현금영수증·세금계산서 칩, 인증서 만료일, 업태·종목·담당 요약, **연결 정보 수정**, **세금계산서 발행**, **현금영수증 발행**.
- 페이지 맨 위에는 상태 코드 배너가 없습니다. 추가 브랜드는 사업자번호, 상호, 대표자, 주소, 사업자등록증을 올리고 **검토 요청**을 합니다. 승인 전에는 바로빌에 가입하지 않습니다. 반려되면 **다시 제출**할 수 있습니다. 개인(비사업자)은 가입 버튼이 꺼지고 안내만 보입니다.
- Standard보다 낮은 요금제에서는 메뉴에 자물쇠와 **Standard부터**가 붙습니다.

## 현금영수증

**클릭 경로:** 로그인 → 상단 「서비스접수」 → 「영수증」 → 「현금영수증」

- 제목 왼쪽에 **현금영수증**, 오른쪽에 지갑 잔액, **충전**, **+ 현금영수증 발행**이 있습니다.
- 그 아래 카드 세 장: **이번 달 발행**, **국세청 전송**(대기·실패), **이번 달 비용**. 실패가 0이면 회색 글자입니다. 1건 이상이면 빨강 밑줄(red-700 #b91c1c)이고, 누르면 실패만 봅니다. 고객명은 연결된 접수 고객입니다. ⋯에 **접수 연결**이 있습니다.
- 필터는 **당일**, **이번주**, **월별**, **날짜**, 상태, 브랜드, 고객명·번호입니다.
- **+ 현금영수증 발행**은 가운데 창입니다. 고객 검색 또는 **직접 입력**, 금액과 발행 가능 한도, 공급가액·부가세, 용도 세 칸, 이메일, 품목명, 오늘·어제, **+ 내부 메모 추가 (고객에게 안 보임)**. 하단은 발행 비용 22원과 **발행하기**입니다. 잔액이 부족하면 빨강 **잔액이 부족합니다**와 **충전하기**입니다.
- 줄의 보이는 버튼은 하나. 정상은 **영수증**, 실패는 **다시 발행**. **공유 링크 복사**, **인쇄/PDF**, **취소**는 ⋯입니다. 실패 이유는 줄 안에 한 줄로 보입니다.
- **충전**은 **청소비서 지갑 충전** 창입니다. 알림톡의 **충전**과 같은 창입니다. 금액은 50,000·100,000·150,000·200,000. 시험 환경에서만 **1,000 TEST**. 기본은 **카드 결제 · 즉시 반영**이고, 버튼은 **N원 카드로 결제**입니다. 무통장은 **입금했어요 · N원 충전 신청**입니다.
- 브랜드가 연결되지 않으면 「계산서 연결을 먼저 해주세요」와 **계산서 연결로 가기**만 보입니다.
- Free에서는 메뉴에 자물쇠와 **Standard부터**가 붙습니다.

## 세금계산서

**클릭 경로:** 로그인 → 상단 「서비스접수」 → 「영수증」 → 「세금계산서」

- 제목 옆에 지갑 잔액, **충전**, **+ 세금계산서 발행**이 있습니다. 줄 순서는 발급일시, 고객, 상호, 사업자번호, 과세구분, 품목, 금액, 영수/청구, 상태, 승인번호입니다. 발급일시는 **10.29 21:27**처럼 월.일 시:분입니다. 고객은 접수 고객명이고, 없으면 공급받는자 성명입니다. 사업자번호는 123-45-***** 입니다. 승인번호는 줄이고, 마우스를 올리면 전체와 **복사**가 나옵니다. **국세청 전송**의 실패는 국세청 전송 실패만 셉니다. **발행 실패**는 바로빌이 거절한 건이고, 누르면 그 건만 봅니다. ⋯에 **접수 연결**이 있습니다.
- 공동인증서가 없거나 만료면 표 위에 「공동인증서를 등록해야 세금계산서를 발행할 수 있습니다」와 **공동인증서 등록**이 나오고, 발행 버튼이 꺼집니다. 배너는 amber-50 배경, amber-300 테두리, amber-950 글자(#fffbeb / #fcd34d / #451a03)입니다. 제목 오른쪽 칩은 **인증서 미등록**(같은 주황) 또는 **인증서 ~만료일**(emerald-50 #ecfdf5, emerald-800 #065f46)입니다. 배너·칩·계산서 연결이 같은 등록 창을 엽니다. 등록이 확인되면 배너가 사라지고 발행이 켜집니다.
- **+ 세금계산서 발행**은 `/admin/inquiries/receipts/taxinvoice/new` 화면으로 이동합니다. PC는 종이 양식입니다. 공급자 글자는 #c8102e, 칸선은 #f0b7c0입니다. 공급받는자 글자는 #1d4ed8, 칸선은 #b9c8f3입니다. 공급자 칸의 **공급자 정보 수정**에서 대표자·주소를 고칩니다. 비어 있으면 그 버튼이 주황입니다. 위쪽 **과세 구분**은 과세·영세·면세입니다. 면세를 고르면 제목이 전자계산서가 되고 세액 칸이 사라집니다. 모바일은 같은 색 띠의 카드이고, 하단 버튼은 **미리보고 발행**입니다. 비용은 세 종류 모두 150원입니다.
- 연결 전에는 「계산서 연결을 먼저 해주세요」와 **계산서 연결로 가기**만 보입니다.
- 접수의 견적서가 있으면 공급받는자 이름·이메일·주소가 채워집니다. 사업자등록번호·대표자는 직접 넣습니다.
- 과세만 발행합니다. 영수 또는 청구, 작성일자를 고릅니다. 품목 합계를 넣으면 공급가액과 세액을 나누고, 고칠 수 있습니다.
- **내부 메모**는 청소비서에만 남습니다.
- 상태는 **발급 취소**, **국세청 전송 대기 · M.D 14시**(파랑 #e8f0ff / #b9cdf7 / #1f4fb8), **국세청 전송 완료**(초록 #e3f6ec / #a9dfc1 / #126b3f), **발행 실패**(바로빌이 거절), **전송 실패**(국세청 전송만), **수정됨**입니다. 발급된 건이면 전송 전에도 ⋯에 **수정 발급 (취소·금액 변경)**이 있습니다. 전송 전이면 그 위에 **발급 취소**가 있고 구분선으로 나뉩니다. 수정 발급은 계약의 해제, 공급가액 변동, 기재사항 착오(2장)입니다. 수정된 줄은 「수정 · 원래 M.D 건」이고, 원래 줄 칩은 **수정됨**입니다. 성공한 장마다 150원입니다.
- 인증서 만료 30일 전부터 노란 띠(#fff6dc / #f0d27a / #7a5300)와 **인증서 다시 등록**이 나옵니다. 만료되면 빨간 띠이고 발행이 막힙니다. 발행 버튼 위 한 줄은 그 회원사의 국세청 전송 설정입니다. 익일이면 「국세청 전송: 다음 날 오후 2시 (그 전까지 발급 취소 가능)」, 즉시면 「발급 즉시 국세청에 전송돼요. 취소는 수정세금계산서로만 할 수 있어요.」
- 각 줄에 **이미지**, **PDF**, **공유**가 있습니다. 고객에게 주는 그림에는 「확인용 사본」과 국세청 승인번호가 있습니다.
- **공동인증서 등록** 창 제목은 그대로입니다. 본문은 「세금계산서를 발행하려면 사업자 공동인증서가 필요합니다. 1년에 한 번.」이고, 버튼은 **등록 창 열기**입니다. 확인이 안 되면 안내 옆에 보조 버튼 **다시 확인**, **다시 열기**가 있습니다. 끝나면 「등록 완료」와 **세금계산서 발행하기**가 보입니다.
- 발행 1건에 150원이 지갑에서 빠집니다. 공동인증서가 없거나 간이과세자면 발행되지 않습니다. 현금영수증은 그대로 됩니다.
- Free에서는 메뉴에 자물쇠와 **Standard부터**가 붙습니다.
