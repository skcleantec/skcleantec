# 관리자 전용

갱신일: **2026-09-28**

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 왼쪽에서 선택

관리자만 보입니다. 각 화면 **메뉴 제목 옆 ?**, 등록·수정 창 **제목 옆 ?** 로 그 화면만 쉬운 설명이 나옵니다.

## 사용자 등록

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「사용자 등록」 → 사람 선택 → 「상세·수정」

- 팀장·마케터·사무 계정을 만들고 고칩니다.
- 「사원증 사진」을 올리면 손님이 볼 인증 사진으로 씁니다.
- 사진이 있으면 **미리보기**(크게 보기)와 **다운로드**(파일로 받기)가 있습니다. 사진을 눌러도 크게 보고, 큰 화면에서 **사진 저장**할 수 있습니다.
- **사진 교체** · **삭제**는 그대로입니다.

| 무엇이 보이는가 | 의미 (쉬운 말) | 화면 토큰 | hex (기준색) | 투명도 |

| 미리보기·다운로드 버튼 | 사원증 보기·받기 | slate-800 | #1e293b | 없음 |
| 버튼 테두리 | 흰 카드 위 보조 버튼 | slate-300 | #cbd5e1 | 없음 |

## PG신청

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「업체등록정보」 → 「PG신청」

화면 제목은 **PG신청**입니다. 연결 전에는 안내 이미지와 **미연결·심사중·반려**, **신청서 · 심사 · 연결**, **PG 신청하기**가 있습니다. 연결되면 안내 대신 **연결됨**과 결제 표(결제일, 팀장, 고객, 접수번호, 방식, 상태, 결제액, 수수료, 실수령)가 나옵니다. 상태는 결재완료·취소·실패 등이고, 방식은 수기결재·고객링크결재입니다. 원성 로그인 주소는 이 화면에 없습니다.

- **PG 신청하기**를 누르면 신청서가 열립니다.
- 상호, 사업자번호, 대표자, 담당 연락처, 정산 계좌를 적고 「PG 신청 제출」을 누릅니다.
- 청소비서에 사업자등록증이 있으면 그 파일이 전달됩니다. 없으면 이미지를 올려야 제출할 수 있습니다.
- 페이지 맨 위에는 **원성페이먼츠 PG 연동** 안내 이미지가 있습니다.
- 카드번호는 받지 않습니다.

| 미연결 | 아직 신청하지 않음 | amber-50 / amber-900 | #fffbeb / #78350f | 없음 |
| 심사중 | 제출한 신청을 확인 중 | slate-50 / slate-800 | #f8fafc / #1e293b | 없음 |
| 연결됨 | 카드 결제가 연결됨 | emerald-50 / emerald-800 | #ecfdf5 / #065f46 | 없음 |
| 반려 | 다시 신청할 수 있음 | red-50 / red-800 | #fef2f2 / #991b1b | 없음 |
| 카드 결제 · 원성페이먼츠 PG | 위쪽 안내 띠 | slate-900 | #0f172a | 없음 |
| 신청서 · 심사 · 연결 | 진행 단계. 지금 단계는 진한 원, 지난 단계는 초록 | slate-900 / emerald-600 | #0f172a / #059669 | 없음 |

## 플랜에 없는 메뉴

**클릭 경로:** 로그인 → 상단 메뉴 이름 옆 자물쇠 → **업그레이드 보기**

- 지금 요금제에 없는 상위 메뉴는 상단에 남고, 하위 메뉴 잠금은 왼쪽 메뉴에만 있습니다.
- 업체가 끈 기능은 잠금으로 보이지 않고 메뉴에서 빠집니다.

## 1인 업체 가계부

**클릭 경로:** 로그인(1인 업체 관리자) → 상단 「가계부」 또는 휴대폰 하단 「가계부」

- 사장 본인의 수입·지출입니다. 팀장 가계부 조회 화면이 아닙니다.
- 월 합계 아래 날짜별 내역이 있고, 접수와 연결된 줄이 있습니다.
- 버튼 **수입/지출 추가**는 slate-900 `#0f172a` 흰 글자입니다. **내 접수 불러오기**와 **설정**은 흰 배경에 slate-800 `#1e293b` 글자입니다.

## 팀장 가계부

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「팀장 가계부」 → **임금 설정**

- 톱니바퀴 **임금 설정**을 누르면 한 창입니다. 위에서 팀장을 고르고 잔금·일당·월급을 정합니다.
- 일당이면 **건마다**(현장 1줄) 또는 **하루 통합**(같은 날 1줄)을 고릅니다.
- **팀장이 임금 설정을 바꿀 수 있음**을 끄면 팀장 가계부에서 설정을 못 바꿉니다.
- 아래 표에 팀장별 현재 방식이 나옵니다. 줄을 누르면 그 팀장이 위에 선택됩니다.

| 무엇이 보이는가 | 의미 (쉬운 말) | 화면 토큰 | hex (기준색) | 투명도 |
|----------------|----------------|-----------|--------------|--------|
| 임금 설정 | 창을 염 | slate-900 글자, 흰 버튼 | #0f172a | 없음 |
| 저장·스위치 켜짐 | 그 팀장 임금을 저장, 팀장 수정 허용 | slate-900 | #0f172a | 없음 |
| 스위치 꺼짐 | 팀장이 임금을 못 바꿈 | slate-300 | #cbd5e1 | 없음 |

## 계산서 연결

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「계산서 연결」

- 영업브랜드마다 카드가 있습니다. 상호·사업자번호·대표자는 사업자정보에 적어 둔 내용이 채워집니다.
- 기본 브랜드는 사업자정보에 적어 둔 번호로 **바로빌 가입**을 합니다. 버튼은 slate-900 `#0f172a` 흰 글자입니다.
- 추가 브랜드는 사업자번호, 상호, 대표자, 주소, 사업자등록증을 올리고 **검토 요청**을 합니다. 승인 전에는 바로빌에 가입하지 않습니다. 반려되면 **다시 제출**할 수 있습니다.
- 개인(비사업자)은 가입 버튼이 꺼지고 안내만 보입니다.
- Standard보다 낮은 요금제에서는 메뉴에 자물쇠와 **Standard부터**가 붙습니다.

## 현금영수증

- 발급일과 상태, 브랜드로 거릅니다. 표에는 구분, 금액, 국세청 상태가 있습니다.
- **현금영수증 발행**은 이 목록 위에서 합니다. 고객명·전화번호로 접수를 찾거나, 매칭 없이 발행할 수 있습니다. 목록에서 취소합니다.

- Free에서는 메뉴에 자물쇠와 **Standard부터**가 붙습니다.

## 세금계산서

**클릭 경로:** 로그인 → 상단 「서비스접수」 → 「영수증」 → 「세금계산서」

- 연결 전에는 「계산서 연결을 먼저 해주세요」와 **계산서 연결로 가기**만 보입니다.
- **세금계산서 발행**에서 고객명·전화번호로 접수를 찾습니다. 매칭 없이 발행할 수도 있습니다.
- 접수의 견적서가 있으면 공급받는자 이름·이메일·주소가 채워집니다. 사업자등록번호·대표자는 직접 넣습니다.
- 과세만 발행합니다. 영수 또는 청구, 작성일자를 고릅니다. 품목 합계를 넣으면 공급가액과 세액을 나누고, 고칠 수 있습니다.
- **내부 메모**는 청소비서에만 남습니다.
- 국세청 전송 전만 **발급취소**가 됩니다. 전송 후에는 「수정세금계산서는 추후 지원」이 보입니다.
- 연결된 브랜드의 **공동인증서 등록**은 우리 창에서 한다. 현금영수증만 쓰면 「세금계산서를 쓸 때만 필요」 안에 접혀 있다.
- 발행 1건에 150원이 지갑에서 빠집니다. 공동인증서가 없거나 간이과세자면 발행되지 않습니다. 현금영수증은 그대로 됩니다.
- Free에서는 메뉴에 자물쇠와 **Standard부터**가 붙습니다.
