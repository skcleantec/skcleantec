# 관리자 전용

갱신일: **2026-09-28**

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 왼쪽에서 선택

관리자만 보입니다. 각 화면 **메뉴 제목 옆 ?**, 등록·수정 창 **제목 옆 ?** 로 그 화면만 쉬운 설명이 나옵니다.

## 사용자 등록

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「사용자 등록」 → 사람 선택 → 「상세·수정」

- 팀장·마케터·사무 계정을 만들고 고칩니다.
- 「사원증 사진」을 올리면 손님이 볼 인증 사진으로 씁니다.
- 사진이 있으면 **미리보기**(크게 보기)와 **다운로드**(파일로 받기)가 있습니다. 사진을 눌러도 크게 보고, 큰 화면에서 **사진 저장**할 수 있습니다.
- **사진 교체** · **삭제**는 그대로입니다.

| 무엇이 보이는가 | 의미 (쉬운 말) | 화면 토큰 | hex (기준색) | 투명도 |
|----------------|----------------|-----------|--------------|--------|
| 미리보기·다운로드 버튼 | 사원증 보기·받기 | slate-800 | #1e293b | 없음 |
| 버튼 테두리 | 흰 카드 위 보조 버튼 | slate-300 | #cbd5e1 | 없음 |
| 사진 칸 테두리 | 올린 사진 | slate-200 | #e2e8f0 | 없음 |

## PG신청

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「업체등록정보」 → 「PG신청」

화면 제목은 **PG신청**입니다. 연결 전에는 안내 이미지와 **미연결·심사중·반려**, **신청서 · 심사 · 연결**, **PG 신청하기**가 있습니다. 연결되면 안내 대신 **연결됨**과 결제 표(결제일, 팀장, 고객, 접수번호, 방식, 상태, 결제액, 수수료, 실수령)가 나옵니다. 상태는 결재완료·취소·실패 등이고, 방식은 수기결재·고객링크결재입니다. 원성 로그인 주소는 이 화면에 없습니다.

- **PG 신청하기**를 누르면 신청서가 열립니다.
- 상호, 사업자번호, 대표자, 담당 연락처, 정산 계좌를 적고 「PG 신청 제출」을 누릅니다.
- 청소비서에 사업자등록증이 있으면 그 파일이 전달됩니다. 없으면 이미지를 올려야 제출할 수 있습니다.
- 페이지 맨 위에는 **원성페이먼츠 PG 연동** 안내 이미지가 있습니다.
- 카드번호는 받지 않습니다.

## 플랜에 없는 메뉴

**클릭 경로:** 로그인 → 상단 메뉴 이름 옆 자물쇠 → **업그레이드 보기**

- 지금 요금제에 없는 상위 메뉴는 상단에 남고, 하위 메뉴 잠금은 왼쪽 메뉴에만 있습니다.
- 업체가 끈 기능은 잠금으로 보이지 않고 메뉴에서 빠집니다.

## 1인 업체 가계부

**클릭 경로:** 로그인(1인 업체 관리자) → 상단 「가계부」 또는 휴대폰 하단 「가계부」

- 사장 본인의 수입·지출입니다. 팀장 가계부 조회 화면이 아닙니다.
- 월 합계 아래 날짜별 내역이 있고, 접수와 연결된 줄이 있습니다.
- 버튼 **수입/지출 추가**는 slate-900 `#0f172a` 흰 글자입니다. **내 접수 불러오기**와 **설정**은 흰 배경에 slate-800 `#1e293b` 글자입니다.

## 팀장 가계부

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「팀장 가계부」 → **임금 설정**

- 톱니바퀴 **임금 설정**을 누르면 한 창입니다. 위에서 팀장을 고르고 잔금·일당·월급을 정합니다.
- 일당이면 **건마다**(현장 1줄) 또는 **하루 통합**(같은 날 1줄)을 고릅니다.
- **팀장이 임금 설정을 바꿀 수 있음**을 끄면 팀장 가계부에서 설정을 못 바꿉니다.
- 아래 표에 팀장별 현재 방식이 나옵니다. 줄을 누르면 그 팀장이 위에 선택됩니다.

| 무엇이 보이는가 | 의미 (쉬운 말) | 화면 토큰 | hex (기준색) | 투명도 |
|----------------|----------------|-----------|--------------|--------|
| 임금 설정 | 창을 염 | slate-900 글자, 흰 버튼 | #0f172a | 없음 |
| 저장·스위치 켜짐 | 그 팀장 임금을 저장, 팀장 수정 허용 | slate-900 | #0f172a | 없음 |
| 스위치 꺼짐 | 팀장이 임금을 못 바꿈 | slate-300 | #cbd5e1 | 없음 |

## 계산서 연결

**클릭 경로:** 로그인 → 상단 「관리자 전용」 → 「계산서 연결」

- 영업브랜드마다 카드가 있습니다. 아직 가입 전이면 그 카드 안에 **연결 정보 입력**(업태·종목·전화·이메일)과 **바로빌 연결하기**가 있습니다. 칸이 비면 버튼이 꺼집니다. 버튼은 slate-900 `#0f172a` 흰 글자입니다.
- 가입이 끝나면 입력칸이 사라지고, 상호·사업자번호, 현금영수증·세금계산서 사용 가능, 업태·종목·가려진 전화·이메일이 보입니다. **수정**을 누르면 같은 칸을 고칩니다.
- 검토 중·반려·연결 필요는 카드 위에 배너가 있습니다. 반려는 **다시 제출**, 연결 필요는 **연결하기**입니다.
- 추가 브랜드는 사업자번호, 상호, 대표자, 주소, 사업자등록증을 올리고 **검토 요청**을 합니다. 승인 전에는 바로빌에 가입하지 않습니다. 반려되면 **다시 제출**할 수 있습니다.
- 개인(비사업자)은 가입 버튼이 꺼지고 안내만 보입니다.
- Standard보다 낮은 요금제에서는 메뉴에 자물쇠와 **Standard부터**가 붙습니다.

## 현금영수증

**클릭 경로:** 로그인 → 상단 「서비스접수」 → 「영수증」 → 「현금영수증」

- 제목 왼쪽에 **현금영수증**, 오른쪽에 지갑 잔액, **충전**, **+ 현금영수증 발행**이 있습니다.
- 그 아래 카드 세 장: **이번 달 발행**, **국세청 전송**(대기·실패), **이번 달 비용**. 실패가 0이면 회색 글자입니다. 1건 이상이면 빨강 밑줄(red-700 #b91c1c)이고, 누르면 실패만 봅니다.
- 필터는 **당일**, **이번주**, **월별**, **날짜**, 상태, 브랜드, 고객명·번호입니다.
- **+ 현금영수증 발행**은 가운데 창입니다. 고객 검색 또는 **직접 입력**, 금액과 발행 가능 한도, 공급가액·부가세, 용도 세 칸, 이메일, 품목명, 오늘·어제, **+ 내부 메모 추가 (고객에게 안 보임)**. 하단은 발행 비용 22원과 **발행하기**입니다. 잔액이 부족하면 빨강 **잔액이 부족합니다**와 **충전하기**입니다.
- 줄의 보이는 버튼은 하나. 정상은 **영수증**, 실패는 **다시 발행**. **공유 링크 복사**, **인쇄/PDF**, **취소**는 ⋯입니다. 실패 이유는 줄 안에 한 줄로 보입니다.
- **충전**은 **청소비서 지갑 충전** 창입니다. 알림톡의 **충전**과 같은 창입니다. 금액은 50,000·100,000·150,000·200,000. 시험 환경에서만 **1,000 TEST**. 기본은 **카드 결제 · 즉시 반영**이고, 버튼은 **N원 카드로 결제**입니다. 무통장은 **입금했어요 · N원 충전 신청**입니다.
- 브랜드가 연결되지 않으면 「계산서 연결을 먼저 해주세요」와 **계산서 연결로 가기**만 보입니다.
- Free에서는 메뉴에 자물쇠와 **Standard부터**가 붙습니다.

| 무엇이 보이는가 | 의미 (쉬운 말) | 화면 토큰 | hex (기준색) | 투명도 |
|----------------|----------------|-----------|--------------|--------|
| 발급완료 | 발급이 됨 | emerald-50 배경, emerald-800 글자 | #ecfdf5 / #065f46 | 없음 |
| 전송중·대기 | 국세청으로 보내는 중 | slate-100 배경, slate-700 글자 | #f1f5f9 / #334155 | 없음 |
| 실패 | 발행 또는 전송이 실패함 | red-50 배경, red-800 글자 | #fef2f2 / #991b1b | 없음 |
| 취소 | 전액 취소. 글자에 취소선 | slate-100 배경, slate-500 글자 | #f1f5f9 / #64748b | 없음 |
| 확인 필요 | 상태가 아직 정해지지 않음 | amber-50 배경, amber-900 글자 | #fffbeb / #78350f | 없음 |
| 잔액이 부족합니다 | 발행 비용보다 잔액이 적음. 충전하기 | red-700 글자, 버튼 slate-900 | #b91c1c / #0f172a | 없음 |
| 1,000 TEST | 시험 환경에서만 보이는 충전 금액 | 선택 시 slate-900 | #0f172a | 없음 |

## 세금계산서

**클릭 경로:** 로그인 → 상단 「서비스접수」 → 「영수증」 → 「세금계산서」

- 제목 옆에 지갑 잔액, **충전**, **+ 세금계산서 발행**이 있습니다. 목록 구조는 현금영수증과 같습니다.
- 공동인증서가 없거나 만료면 표 위에 「공동인증서를 등록해야 세금계산서를 발행할 수 있습니다」와 **공동인증서 등록**이 나오고, 발행 버튼이 꺼집니다. 배너는 amber-50 배경, amber-300 테두리, amber-950 글자(#fffbeb / #fcd34d / #451a03)입니다. 제목 오른쪽 칩은 **인증서 미등록**(같은 주황) 또는 **인증서 ~만료일**(emerald-50 #ecfdf5, emerald-800 #065f46)입니다. 배너·칩·계산서 연결이 같은 등록 창을 엽니다. 등록이 확인되면 배너가 사라지고 발행이 켜집니다.
- **+ 세금계산서 발행**은 `/admin/inquiries/receipts/taxinvoice/new` 화면으로 이동합니다. PC에서는 공급자 칸이 빨강(red-600 #dc2626, 제목 red-700 #b91c1c), 공급받는자 칸이 파랑(blue-600 #2563eb, 제목 blue-700 #1d4ed8)인 전자세금계산서 양식입니다. 모바일은 같은 색 띠의 세로 카드이고, 하단 고정 버튼은 **발행하기**입니다. 비용은 150원입니다.
- 연결 전에는 「계산서 연결을 먼저 해주세요」와 **계산서 연결로 가기**만 보입니다.
- 접수의 견적서가 있으면 공급받는자 이름·이메일·주소가 채워집니다. 사업자등록번호·대표자는 직접 넣습니다.
- 과세만 발행합니다. 영수 또는 청구, 작성일자를 고릅니다. 품목 합계를 넣으면 공급가액과 세액을 나누고, 고칠 수 있습니다.
- **내부 메모**는 청소비서에만 남습니다.
- 국세청 전송 전만 **발급취소**가 됩니다. 전송 후에는 「수정세금계산서는 추후 지원」이 보입니다.
- 각 줄에 **이미지**, **PDF**, **공유**가 있습니다. 고객에게 주는 그림에는 「확인용 사본」과 국세청 승인번호가 있습니다.
- **공동인증서 등록** 창 제목은 그대로입니다. 본문은 「세금계산서를 발행하려면 사업자 공동인증서가 필요합니다. 1년에 한 번.」이고, 버튼은 **등록 창 열기**입니다. 끝나면 「등록 완료」와 **세금계산서 발행하기**가 보입니다.
- 발행 1건에 150원이 지갑에서 빠집니다. 공동인증서가 없거나 간이과세자면 발행되지 않습니다. 현금영수증은 그대로 됩니다.
