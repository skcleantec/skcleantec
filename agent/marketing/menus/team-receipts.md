# 팀장 현금영수증 · 세금계산서

## 경로

- 컴퓨터 상단·휴대폰 메뉴: **현금영수증** → `/team/cashbill`
- 컴퓨터 상단·휴대폰 메뉴: **세금계산서** → `/team/taxinvoice`
- 배정 상세 하단: **현금영수증** (세금계산서 탭 없음). 세금계산서 발행은 세금계산서 메뉴의 **+ 새로 발행**만.

기능이 꺼진 업체에는 두 메뉴가 없습니다.

## 하는 일

각 화면은 제목, **+ 새로 발행**, 내가 발행한 내역입니다.

내역 한 줄의 버튼은 **영수증 보기** | **공유하기** | **취소**입니다. 승인 전·이미 취소된 건은 취소가 흐립니다.

**공유하기**는 휴대폰 공유 창입니다. 글은 `[브랜드명] 현금영수증 · 350,000원`이고, 주소는 청소비서 영수증입니다. 컴퓨터에서는 링크를 복사하고 가운데에 **링크를 복사했어요**가 잠깐 나옵니다.

**취소**는 가운데 확인 후 바로 취소됩니다. 본인이 발행한 건만 됩니다. 세금계산서는 국세청 전송 전이면 발급 취소, 전송 후면 취소분입니다. 관리자 알림함에는 `[현금영수증] ○○ 팀장이 ○○ 350,000원을 취소했습니다.`가 옵니다.
