# 추가 시공 사진으로 견적 범위를 보여 주는 앱 (계획)

이 문서는 나중에 만들 별도 앱의 계획이다. 청소비서 안에 모델, 화면, 학습 API는 없다.

## 무엇을 하나

고객이 자기 집 사진을 올리면, 마케터가 현장에서 남겨 둔 사진·시공 내용·공간·실제 받은 금액과 비슷한 경우를 찾아 **금액 범위**를 보여 준다. 확정 금액이 아니다. 현장 확인 전 예상이다.

금액은 우리 현장 기록에서만 나온다. 모델이 임의 가격을 만들지 않는다.

## 학습에 쓰는 칸

추가 시공 내역에 이미 있다.

- 사진
- 시공 내용
- 공간 (방, 발코니, 화장실, 주방, 거실)
- 실제 받은 금액

고객 이름, 전화, 주소, 접수번호는 학습 묶음에 넣지 않는다. 접수와 사진 파일을 분리해서 뺀다.

## 켜기

업체 설정 `allowTraining` 이 켜지기 전에는 사진을 견적 앱으로 내보내지 않는다. 기본은 꺼짐. 사진은 정산 증빙으로만 남는다.

## 하지 않는 것

- 지금 학습을 돌리기
- 고객용 촬영 화면을 청소비서에 넣기
- 접수 잔금이나 카드결제에 예상 금액을 더하기
