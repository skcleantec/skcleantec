# 공급자 정보가 나뉜 곳

세금계산서 공급자(상호·대표자·주소)는 아직 한 곳에 모이지 않는다. 이번 문서는 화면이 어디를 읽고 쓰는지 정리한다. 저장소를 하나로 합치는 작업은 다음에 한다.

빈 문자열·공백·안내 문구는 공급자 칸을 덮어쓰지 않는다. 사업자정보 저장에서 상호가 비어 있으면 저장 전에 「상호를 입력해 주세요」로 막는다.

| 저장 위치 | 담는 것 | 읽는 화면 | 쓰는 화면 |
|---|---|---|---|
| `TenantSignupBusiness` | 가입 때 남긴 상호·대표자·주소 | 계산서 연결의 기본 브랜드 가입. 여기 값을 회원사로 복사한다 | 가입 완료. 기본 브랜드 공급자 정보 수정. 사업자정보 저장 중 실제 값이 있는 칸만 |
| `Tenant.config` 의 `companyRegistration` | 업체 기본 사업자정보. 관리자 전용 → 사업자정보 화면이 여기를 쓴다 | 사업자정보 화면. 견적서·발주서가 브랜드 값이 없을 때 쓰는 기본값 | 사업자정보 저장. 기본 브랜드 공급자 정보 수정 |
| `OperatingCompany.config` 의 `companyRegistration` | 그 브랜드만의 견적 공급자. 비어 있으면 업체 기본값을 쓴다 | 견적서, 발주서 공급자 표시 | 관리자 전용 → 영업브랜드의 사업자 정보 칸 |
| `BarobillMember` | 세금계산서·현금영수증에 나가는 공급자 | 세금계산서 발행, 계산서 연결 카드 | 바로빌 연결. 공급자 정보 수정. 사업자정보 저장은 기본 브랜드만, 빈 칸은 그대로 둔다 |

발행 화면의 공급자는 `BarobillMember`만 본다. 사업자정보 화면의 상호가 비어 있어도, 그 빈 값으로 회원사 상호를 지우지 않는다.
