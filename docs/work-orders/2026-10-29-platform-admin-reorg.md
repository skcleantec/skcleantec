## 진단 (staging 34f68961 기준 조사 완료 — 다시 조사하지 말 것)
1. **업체 1곳 설정이 6곳에 흩어짐**
   - 업체 상세(`PlatformTenantDetailPage` 793줄 한 페이지): 기본정보·사업자·플랜·기능 모듈·화면 표시·텔레CRM·알림톡·사용량·이용료 계약·관리자·위험구역
   - 결제 관리(`/platform/billing`): 업체별 청구 상태·액션 큐
   - 카드결제 PG(`/platform/card-payment`): **업체 결제 키**·가입 신청
   - 전자계약(`/platform/card-payment/e-contract`): PG 계약서
   - 현금영수증 회원(`/platform/barobill-members`): 바로빌 가입·검토
   - 업체 목록: 코인·AI 사용
2. **기능 켜기가 3겹**: 플랜 → 「기능 모듈 개별 설정」 → 「화면 표시 설정」(메뉴별). 최종적으로 켜졌는지·왜인지 한눈에 안 보임.
3. **"돈" 메뉴가 성격이 다른 것끼리 섞임**: 우리가 받는 이용료(결제 관리·정산·카드결재) + 업체에게 붙여주는 서비스(카드결제 PG·전자계약·현금영수증 회원). 「카드결제」/「카드결재」 이름 중복.
4. **숨은 페이지**: 설정(SMTP·이용료 알림·고객 메일·사업자 정보·약관)은 사이드 메뉴에 없음(프로필 링크만). 수수료 현황(`/platform/card-payment/fees`)은 탭에서만. 입금 계좌·연체 유예는 결제 관리 화면 중간에.
5. **처리할 일이 7곳에 흩어짐**: 가입승인·유료 전환·문의 링크·이용료 입금 확인·알림톡 충전 신청·PG 가입 신청·바로빌 검토/연결 필요·미납.
6. **모호한 이름**: 정보공유(=DB 마켓), 메시지, 정산(실제로는 입금 내역), 카드결재(이용료 수기 결제).

## 목표 메뉴 (6개)

```
🏠 오늘 할 일        승인·확인 대기 전부 한 목록 (건수 배지)
🏢 업체              업체 목록 · 업체 추가 · (업체 상세 = 탭)
💰 매출·수납         이용료 청구 · 입금 내역 · 수기 카드결제 · 수익 현황(PG 수수료·바로빌 마진·추천인 수수료)
🧩 부가서비스        카드결제 PG · 계산서(바로빌) · 알림톡 · DB 마켓
📣 마케팅·고객       가입 체험 이벤트 · 추천인 · 안내 팝업 · 고객센터 · 도움말 · 메시지
⚙ 설정              우리 회사 정보 · 입금 계좌·연체 · 메일(SMTP·템플릿) · 약관 · 이용료 알림 · 지원 접속
```

## 업체 상세 = 탭

| 탭 | 내용 (기존 섹션/페이지에서 가져옴) |
|---|---|
| **개요** | 상태 요약 + **설정 체크리스트**(아래) + 최근 활동 |
| **요금·청구** | 플랜 · 체험 · 계약 조건 · 청구서 · 청구 일정 (TenantBillingPanel) |
| **기능** | 모듈 표 1개로 통합 (아래) |
| **부가서비스** | 알림톡(라이선스·충전금·템플릿) · 텔레CRM(좌석) · 카드결제 PG(가입 상태·결제 키) · 계산서(바로빌 회원·인증서) · 코인 |
| **사업자·계정** | 기본정보 · 사업자 정보 · 관리자 계정 |
| **위험** | 정지·삭제 |

**설정 체크리스트(개요 탭)** — 각 줄에 상태와 「설정하러 가기」(해당 탭으로 이동):
사업자 정보 / 플랜·과금 설정 / 관리자 계정 / 알림톡 / 카드결제 PG / 계산서 연결 / 공동인증서(세금계산서 쓸 때).

**기능 탭 통합 표** — 행 = 기능 모듈, 열 = `플랜 기본` · `개별 설정(기본 따름 / 켜기 / 끄기)` · **`최종`(켜짐/꺼짐 + 이유)** · ▸ 펼치면 그 모듈의 메뉴별 표시 토글(기존 「화면 표시 설정」). 기존 데이터 구조 그대로 사용.
