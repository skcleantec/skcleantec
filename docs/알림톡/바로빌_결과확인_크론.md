# 바로빌 알림톡 결과 확인

바로빌로 접수한 알림톡은 바로 성공·실패가 확정되지 않습니다.  
API 서버가 떠 있는 동안 1분마다 결과를 조회해 알림톡 성공, 문자 대체, 실패를 나눕니다.

Railway 크론 서비스는 만들지 않습니다. Railway 크론은 최소 5분이라 1분 주기를 맞출 수 없습니다. 확인은 서버 안에 들어 있습니다.

기본 발송은 솔라피입니다. 서식의 보내는 곳이 바로빌일 때만 이 확인이 건을 집습니다.

## 서버 내장 확인

| 항목 | 값 |
|---|---|
| **주기** | 서버가 뜬 뒤 60초마다 |
| **겹침** | 이전 회차가 끝나지 않았으면 그 회차는 건너뜀 |
| **대기 없음** | `AWAITING_RESULT` 가 0건이면 바로빌을 호출하지 않음 |
| **끄기** | `ALIMTALK_BAROBILL_RESULT_POLL=off` (기본은 켬) |
| **종료** | 배포 교체의 SIGTERM·SIGINT 에서 타이머를 정리 |

서버가 두 대여도 같은 건을 두 번 차감하지 않습니다. 결과를 확정할 때 `AWAITING_RESULT` 인 행만 먼저 다른 상태로 바꾸고, 바뀐 건수가 1일 때만 업체 지갑을 깎습니다.

## 수동 실행

같은 확인을 주소로 한 번 돌릴 수 있습니다. 주기 실행은 이 주소에 의존하지 않습니다.

| 항목 | 값 |
|---|---|
| **경로** | `POST /api/admin/cron/alimtalk-barobill-result` |
| **인증** | `Authorization: Bearer <secret>` 또는 `x-cron-secret` |
| **Secret** | `ALIMTALK_CRON_SECRET` → 없으면 `HAPPY_CALL_CRON_SECRET` → `BILLING_CRON_SECRET` |

```sh
curl -sf -X POST "${CRON_BASE_URL}/api/admin/cron/alimtalk-barobill-result" \
  -H "Authorization: Bearer ${ALIMTALK_CRON_SECRET:-$HAPPY_CALL_CRON_SECRET}"
```

`CRON_BASE_URL` 끝에 `/` 를 붙이지 않습니다. 운영은 `https://www.cbiseo.com`, 스테이징은 스테이징 공개 주소입니다. 비밀값은 이 문서에 적지 않습니다. `checked` 가 숫자로 돌아오면 연결된 것입니다.

## 스테이징

스테이징은 허용된 시험 번호로만 발송합니다. 바로빌 서버는 코드에서 시험용으로 바꾸지 않고, 그 환경의 `BAROBILL_ENV` 값을 그대로 사용합니다.

## 관련 코드

| 파일 | 역할 |
|---|---|

| `server/src/modules/alimtalk/alimtalkBarobillResult.cron.routes.ts` | 수동 실행용 HTTP |
| `server/src/modules/alimtalk/alimtalkBarobillSend.ts` | 바로빌 접수 |
