# 바로빌 알림톡 — 대체문자·템플릿명

운영 발송은 아직 **솔라피**입니다. 이 문서는 바로빌로 바꿀 때 쓰는 **대체문자**와 템플릿명만 적습니다.
솔라피 본문·솔라피 LMS 문구는 `솔라피_템플릿_명세.md` 가 기준이며, 여기서 고치지 않습니다.

바로빌 **알림톡 본문·강조표기·보조문구·버튼**은 이 문서에 적지 않습니다. 카카오 승인 원문을 `GetKakaotalkTemplates`로 받아 저장합니다. 강조표기는 제목 칸, 보조문구(고정 문구)는 보조 칸에 따로 둡니다. 한 글자만 달라도 발송이 거절됩니다.

## 서식 코드 ↔ 바로빌 템플릿명

| 서식 코드 | 바로빌 템플릿명 |
|-----------|-----------------|
| `CBISEO_CUST_ORDER_LINK` | `[고객] 발주서 작성·예약 안내` |
| `CBISEO_CUST_ORDER_DONE` | `[고객] 예약(발주서) 접수 완료` |
| `CBISEO_CUST_SCHEDULE_D2` | `[고객] 예약 일정 확인(무위약 마감일)` |
| `CBISEO_CUST_PAY_LINK` | `[고객] 청소비 결제 안내` |

심사 상태 `3` 이 정상입니다. 채널 상태 `1` 이 정상입니다.

## 우리가 채우는 변수

`#{고객명}` `#{브랜드명}` `#{총금액}` `#{예약금}` `#{청소일}` `#{시간대}` `#{업체명}` `#{문의전화}` `#{발주토큰}` `#{업체코드}` `#{브랜드코드}` `#{접수번호}` `#{주소}` `#{무위약마감일}` `#{동의일시}` `#{결제내용}` `#{결제금액}` `#{결제토큰}`

`#{동의일시}` 는 그 발주서의 제출 시각을 한국시간 `YYYY-MM-DD HH:mm` 으로 넣습니다. 없으면 `—`.

## 버튼 (참고)

실제 버튼 글자와 주소는 동기화 결과를 씁니다. 신청할 때 기준만 적습니다.

| 서식 | 버튼 | 주소 |
|------|------|------|
| ORDER_LINK | 발주서 작성 | `https://www.cbiseo.com/order/#{발주토큰}?tenant=#{업체코드}&brand=#{브랜드코드}` |
| ORDER_DONE · SCHEDULE_D2 | 발주계약서 확인 | 위와 같은 발주서 주소 |
| ORDER_DONE · SCHEDULE_D2 | 안내사항 확인 | `https://www.cbiseo.com/info?tenant=#{업체코드}&brand=#{브랜드코드}` |
| PAY_LINK | 결제하기 | `https://www.cbiseo.com/pay/card/#{결제토큰}` |

보조문구(강조 보조·부가정보)는 변수를 넣지 않는 고정 문구입니다.

## 대체문자

제목은 `barobillSmsSubject`, 본문은 `barobillSmsMessage` 입니다.

### ORDER_LINK

제목은 솔라피 LMS 첫 줄과 같고, 본문은 솔라피 LMS 전체와 같습니다.

제목

```
[청소비서] #{브랜드명} 예약 안내
```

본문

```
[청소비서] #{브랜드명} 예약 안내

#{고객명}님, 입주·이사 청소 예약 안내입니다.

총 #{총금액}원 / 예약금 #{예약금}원
청소일 #{청소일} #{시간대}

발주서 작성 링크
https://www.cbiseo.com/order/#{발주토큰}?tenant=#{업체코드}&brand=#{브랜드코드}

문의 #{문의전화}

본 문자는 예약·접수 플랫폼 청소비서 안내입니다.
실제 청소 서비스는 #{업체명}(#{문의전화})에서 제공합니다.
```

### ORDER_DONE

제목

```
[청소비서] #{브랜드명} 예약 접수 완료
```

본문

```
#{고객명}님, 발주서 접수가 완료되었습니다.

접수번호 #{접수번호}
청소일 #{청소일} #{시간대}
주소 #{주소}
안내·동의사항 확인 #{동의일시} (고객 직접 동의·서명)

발주계약서 확인
https://www.cbiseo.com/order/#{발주토큰}?tenant=#{업체코드}&brand=#{브랜드코드}

[취소·변경·문의]
업체명 #{업체명}
전화번호 #{문의전화}
```

### SCHEDULE_D2

제목

```
[청소비서] #{브랜드명} 청소 일정 안내
```

본문

```
#{고객명}님, 예약하신 청소 일정입니다.

청소일 #{청소일} #{시간대}
주소 #{주소}
무위약 취소·변경 마감 #{무위약마감일}
이 날까지 연락 주시면 위약금 없이 취소·변경됩니다.
이후에는 위약금이 발생할 수 있습니다.

발주계약서 확인
https://www.cbiseo.com/order/#{발주토큰}?tenant=#{업체코드}&brand=#{브랜드코드}

안내사항(취소·위약금 기준)
https://www.cbiseo.com/info?tenant=#{업체코드}&brand=#{브랜드코드}

[취소·변경·문의]
업체명 #{업체명}
전화번호 #{문의전화}
```

### PAY_LINK

제목

```
[청소비서] #{업체명} 결제 안내
```

본문

```
[청소비서] #{업체명} 결제 안내

#{고객명} 님, 청소비 결제를 안내드립니다.

결제 내용: #{결제내용}
결제 금액: #{결제금액}

지금 결제해 주세요.
https://www.cbiseo.com/pay/card/#{결제토큰}

문의: #{문의전화}
```
