# 솔라피(Solapi) 알림톡 도입 상세 플랜

솔라피(Solapi) 알림톡 기능을 멀티테넌트(SaaS) 환경에 맞게 **플랜별 월 무료 건수 + 선불 충전(건당 20원)** 으로 도입하기 위한 상세 개발 플랜입니다.

**제품·과금·템플릿·발송 방식 확정안**은 [`메시지/솔라피_템플릿_명세.md`](./메시지/솔라피_템플릿_명세.md) **「제품·과금·운영 정책 (확정)」** — 구현 시 해당 절을 우선한다.

카카오 알림톡은 일반 SMS와 달리 **사전에 카카오의 승인을 받은 템플릿(서식)만 발송할 수 있다는 강력한 제약**이 있습니다. 따라서 플랫폼(우리)이 서식을 만들고, 테넌트가 이를 선택해 사용하는 구조가 매우 적합합니다.

전체적인 시스템은 **[솔라피 설정] → [DB 설계] → [플랫폼 관리자 기능] → [테넌트 기능] → [백엔드 발송 로직]** 5단계로 나누어 진행합니다.

---

## Phase 1. 솔라피(Solapi) 사전 준비 (플랫폼 차원)

가장 먼저 카카오와 솔라피 측에 비즈니스 인증과 서식을 등록해야 합니다.

1. **카카오톡 비즈니스 채널 개설**: '청소비서' 또는 서비스명으로 카카오톡 채널을 만들고 비즈니스 인증을 받습니다.
2. **솔라피 가입 및 채널 연동**: 솔라피에 가입 후 발신번호 및 카카오톡 채널을 연동합니다.
3. **알림톡 템플릿(서식) 등록 및 승인**:
   - 보낼 메시지 서식을 솔라피에 등록합니다. (예: `#{고객명}님, 예약이 확정되었습니다. 일시: #{예약일}`)
   - 카카오의 심사를 거쳐 승인(보통 1~3일 소요)을 받아야만 API로 발송할 수 있습니다.
   - **등록 본문·변수·버튼·LMS·연동 설계의 단일 기준**: [`메시지/솔라피_템플릿_명세.md`](./메시지/솔라피_템플릿_명세.md) (템플릿 추가 시 반드시 갱신 — `.cursor/rules/alimtalk-template-docs.mdc`)
   - **위약금 구조화 → 안내 치환코드 → D-2 재검수 순서**: [`위약금_치환코드_알림톡_2단계_플랜.md`](./위약금_치환코드_알림톡_2단계_플랜.md)
4. **API Key 발급**: 솔라피 API Key와 API Secret을 발급받아 서버의 `.env` 환경변수에 등록합니다.

## Phase 2. DB 스키마 설계 (Prisma)

플랜별 **월 무료 건수**·**충전 잔액**·**템플릿 ON/OFF**·발송 로그. 상세 필드·과금 순서는 **명세 §제품·과금·운영 정책**.

1. **`AlimtalkTemplate` (플랫폼 공통 서식)**
   - 카카오 승인이 완료된 템플릿을 우리 시스템에 등록하는 테이블입니다.
   - 필드: 솔라피 템플릿 ID, 템플릿 코드(`CBISEO_*`), 템플릿명, **수신자 유형**, **발송 트리거**, **발송 방식**(수동/자동)
2. **`TenantAlimtalkTemplateSetting` (테넌트별 템플릿 ON/OFF)**
   - 플랫폼 「알림톡」 메뉴에서 테넌트별로 **보낼 템플릿만** 활성화.
   - 필드: `tenantId`, `templateCode`, `isEnabled`
3. **`TenantAlimtalkWallet` (테넌트 지갑 — 브랜드 공유)**
   - `prepaidBalanceKrw` (충전 잔액), `monthlyFreeUsed`, `monthlyFreePeriodYm` (KST 월)
   - **브랜드별 지갑 없음** — `tenantId` 단일. 발송 시 `operatingCompanyId` 로 **브랜드명·전화**만 분기.
4. **`AlimtalkChargeRequest` (충전 요청)**
   - **50,000원 단위**, **1회 최대 200,000원**. 입금 확인 후 플랫폼이 승인·반영.
5. **`AlimtalkSendLog` (발송·과금 로그)**
   - `chargeType`: `FREE` | `PAID`(20원), `operatingCompanyId`, `templateCode`, 수신 번호 등.

### 플랜별 월 무료 (확정)

| 플랜 | 알림톡 | 월 무료 |
|------|--------|---------|
| Starter / Free | **불가** | 0 |
| Standard | 가능 | **100건** |
| Standard+ | 가능 | **150건** |
| Premium | 가능 | **200건** |

매월 **KST 1일** 무료 사용량 리셋. 초과분: **ATA 20원/건**, **대체 LMS 60원/건**(무료 잔여 **3건** 미만 시). LMS 성공 시 무료 풀에서 **3건** 소진. 상세: 명세 §2·§8.

## Phase 3. 플랫폼 관리자 (우리가 쓰는 화면) 개발

1. **알림톡 (`/platform/alimtalk`) — 1차 핵심**
   - **테넌트별 현황**: 플랜, 이번 달 무료 사용/잔여, 충전 잔액, 최근 발송
   - **충전금**: 충전 요청 승인·잔액 반영 (5만~20만 규칙)
   - **템플릿 선택**: 테넌트별 **보낼 템플릿만 ON/OFF** (OFF면 수동·자동 모두 미발송)
2. **알림톡 서식 관리 (`/platform/alimtalk-templates`)**
   - 솔라피 승인 `templateId` ↔ `CBISEO_*` 코드 매핑
3. **(선택) 충전 요청 목록** — 위 「알림톡」 화면에 통합 가능

## Phase 4. 테넌트 관리자 (청소업체) — **적용됨**

Standard **이상** + `mod_alimtalk` ON 시 **관리자 전용 → 알림톡** (`/admin/team-leaders/alimtalk`).

1. **이용 현황** — 플랜, 이번 달 무료 사용/잔여, 선불 잔액, 발송 가능 여부 안내
2. **충전 신청** — 5만~20만 원 단위 신청 · 입금 계좌 안내 · **플랫폼 입금 확인 후 반영**
3. **알림톡 종류 ON/OFF** — 3종 기본 ON, `HelpTooltip(?)` 으로 발송 위치·시점 안내
4. **플랫폼** — 업체 상세 「플랜 · 알림톡」에서 **대기 중 충전 신청 승인** + 라이선스·월 무료 정책·즉시 충전 반영

API: `GET/PATCH /api/alimtalk/settings`, `POST /api/alimtalk/charge-requests` (ADMIN 전용)

## Phase 4b. 마케터 UI — 발주 링크 **수동** 알림톡

- **`AdminOrderFormPage`** (발급 완료): **「알림톡 발송」** 버튼 → `CBISEO_CUST_ORDER_LINK` 1건

## Phase 5. 백엔드 핵심 로직 (서버 개발)

실제 돈이 오가고 메시지가 발송되는 핵심 서버 로직입니다.

1. **충전 신청 시 플랫폼 관리자에게 알림톡 발송**
   - 테넌트가 [충전 신청] API를 호출하면, 서버는 `PointChargeRequest`를 PENDING으로 생성합니다.
   - 직후, **플랫폼 관리자의 휴대폰 번호**로 솔라피 API를 호출하여 "OO업체에서 1만원 충전 요청이 들어왔습니다"라는 알림톡을 발송합니다.
2. **비즈니스 로직 곳곳에 발송 트리거(Hook) 심기**
   - 예: 서비스 접수 상태가 '예약완료'로 변경되는 API 로직 끝부분에 `triggerAlimtalk(tenantId, 'INQUIRY_RECEIVED', data)` 함수를 호출합니다.
3. **발송 및 과금 트랜잭션 (가장 중요)**
   - `triggerAlimtalk` 함수 내부 로직:
     1. `Tenant.plan` **≥ standard** (Starter/Free → 거부)
     2. 해당 `templateCode` **테넌트 ON** (`TenantAlimtalkTemplateSetting`)
     3. **브랜드 변수** 빌드 — **`resolveAlimtalkCustomerBrandContext`** (명세 §3.1): 일반 건은 접수 `operatingCompanyId`, **정보공유·파트너 인계(미러) 건**은 **원(송신) 접수·원 테넌트** 브랜드·`tenant`/`brand` URL (`#{브랜드명}`, `#{문의전화}`)
     4. **월 무료**: ATA → 1건 소진, LMS → **3건** 소진(잔여≥3). 부족 시 **ATA 20원 / LMS 60원** 선불 차감
     5. 솔라피 API 발송 → 성공 시 `AlimtalkSendLog` + 지갑 갱신
