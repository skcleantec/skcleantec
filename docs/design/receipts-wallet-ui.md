# 화면 기준서 — 영수증(현금영수증·세금계산서) · 청소비서 지갑 충전

> 2026-10-29 staging(8dfa7d9) 화면 점검 후 작성. DesignPulse 기준서. 이 문서대로만 만든다.
> 대상: `/admin/inquiries/receipts/cashbill`, `/admin/inquiries/receipts/taxinvoice`, 지갑 충전 모달(영수증·알림톡 공용), 지갑 내역.

## 점검에서 나온 문제
1. 영수증 화면 맨 위에 **서비스접수 「이용 순서」 안내(접수 흐름)** 가 그대로 떠서 화면 1/3을 차지. 영수증과 무관.
2. 지갑 카드 · 발행 버튼 · 필터 · 표가 각각 따로 떠 있는 카드라 시선이 흩어짐. 발행 버튼이 혼자 떠 있음.
3. 발행 폼이 화면 전체 폭으로 펼쳐지는 **세로 나열 입력칸**(1,300px 넓이 입력칸). 묶음·순서·요약이 없음.
   - 금액에 단위·한도 안내 없음, 공급가액/부가세 미리보기 없음, 발행 비용(22원)·잔액 안내 없음, 내부 메모 칸 없음, 브랜드 선택 안 보임.
4. 목록에 **고객 이름·번호 칸이 없음**(누구 영수증인지 모름). 「매칭 없음」이 칸 하나를 차지. 줄마다 버튼 4개(공유·인쇄-PDF·영수증 보기·취소).
5. 「실패」 줄에 **이유가 없고** 다시 발행 버튼도 없음.
6. 충전 모달: 무통장 정보가 맨 위, **카드 결제는 아래 보조 버튼**. 두 결제 방식이 섞여 있음. 현재 잔액·충전 후 잔액 없음. 「닫기」 글자 링크. 1,000원 시험결제 없음.
7. 세금계산서: 공동인증서 미등록인데 **아무 안내 없이** 발행 버튼만 있음.

## 공통 규칙
- 이 화면들에는 서비스접수 이용 순서 안내를 **표시하지 않는다**.
- 금액: 오른쪽 정렬, 천 단위 쉼표, "원". 핵심 금액(잔액·발행 금액)은 다른 글자보다 확실히 크게.
- 상태 배지 색: 발급완료/성공 초록 · 전송중/대기 회색 · 실패 빨강 · 취소 회색 취소선 · 확인 필요 주황.
- 주 버튼은 화면당 1개(검정). 나머지는 외곽선 또는 ⋯ 메뉴.
- 모달: 데스크톱 가운데 560px, 휴대폰은 아래에서 올라오는 전체 화면 시트. 닫기는 오른쪽 위 ✕ 아이콘 + Esc.
- 아이콘은 LineMdIcon 만.

## 1. 영수증 목록 화면 (현금영수증·세금계산서 동일 구조)

```
[현금영수증]                                  지갑 49,978원 [충전]   [+ 현금영수증 발행]
┌ 이번 달 발행 ─┐ ┌ 국세청 전송 ─────┐ ┌ 이번 달 비용 ─┐
│ 12건 · 860,000원│ │ 대기 2 · 실패 1 ⚠│ │ 264원          │   ← 실패를 누르면 실패만 필터
└────────────┘ └────────────────┘ └────────────┘
[당일|이번주|월별|날짜] [상태 ▾] [브랜드 ▾]  🔍 고객명·번호
발급일시      고객                    품목        금액     용도      상태        승인번호     
10-29 14:02  김민지 010-****-1234     청소 서비스  500원   소득공제  ●발급완료  TS3959389   [영수증] ⋯
             접수 CB2610290003 ↗
10-28 11:30  (번호 없음·자진발급)     청소 서비스  5,000원  자진발급  ●실패      —            [다시 발행] ⋯
             실패 이유: 잔액 부족(-26006)
```
- 줄의 보이는 버튼은 1개: 정상 = [영수증](바로빌 고객용 화면 새 창), 실패 = [다시 발행]. 나머지(공유 링크 복사·인쇄/PDF·취소)는 ⋯ 메뉴.
- 「접수」 칸 삭제 → 매칭된 경우만 고객 칸 아래 작은 접수번호 링크.
- 실패 이유는 줄 안에 한 줄로 항상 보이게.
- 세금계산서: 공동인증서 미등록/만료면 표 위에 주황 배너 「공동인증서를 등록해야 세금계산서를 발행할 수 있습니다 [등록하기]」, 발행 버튼 비활성.

## 2. 발행 모달 (현금영수증)

```
현금영수증 발행                                              ✕
① 고객      [🔍 고객명 또는 전화번호____________]  ( 직접 입력 )
             └ 검색 결과: 이름 · 번호 · 접수일 · 총액 · 발행 가능 금액
② 금액      [ 33,000 ] 원      발행 가능 한도 33,000원
             공급가액 30,000 · 부가세 3,000
③ 용도      [ 소득공제(휴대폰) | 지출증빙(사업자) | 자진발급 ]   ← 세그먼트
             [ 010-1234-5678 ]   (용도에 따라 라벨·자리수 바뀜)
④ 고객 이메일(선택) [___________]  입력하면 바로빌이 공식 영수증 메일을 보냅니다
⑤ 품목명 [청소 서비스]      거래일 [ 오늘 | 어제 ]
   + 내부 메모 추가 (고객에게 안 보임)
─────────────────────────────────────────────────────
발행 비용 22원 · 지갑 49,978원 → 49,956원          [취소] [발행하기]
```
- 브랜드가 2개 이상인 업체만 ① 위에 브랜드 선택.
- 잔액 부족: 하단 문구 빨강 「잔액이 부족합니다」 + [충전하기](충전 모달 열림), 발행하기 비활성.
- 발행 성공: 모달 닫고 토스트 「발행했습니다 · [영수증 보기] [링크 복사]」, 목록 새 줄 잠깐 강조.
- 세금계산서 모달도 같은 틀: ① 공급받는자(사업자번호·상호·대표자·이메일, 견적서 자동채움) ② 품목 줄 ③ 합계/공급가/세액 ④ 영수·청구, 작성일 → 하단 비용 150원 요약.

## 3. 지갑 충전 모달 (영수증·알림톡 공용 컴포넌트 1개)

```
청소비서 지갑 충전                                           ✕
현재 잔액 49,978원
충전 금액  [ 50,000 ] [ 100,000 ] [ 150,000 ] [ 200,000 ]  ( [1,000 TEST] ← 시험결제 켜진 환경만 )
           충전 후 잔액 99,978원
결제 방법  [ 카드 결제 · 즉시 반영 | 무통장 입금 · 확인 후 반영 ]   ← 기본: 카드
── 카드 ──
  결제창에서 카드 정보를 입력합니다. 승인되면 바로 잔액에 들어갑니다.
                                         [ 50,000원 카드로 결제 ]
── 무통장 ──
  IBK기업은행 338-089444-04-010 (주)서비스브릿지   [복사]
  입금자명 [업체명 기본값]   ← 필수
  입금 후 아래 버튼을 눌러주세요. 확인되면 알림으로 알려드립니다.
                                         [ 입금했어요 · 50,000원 충전 신청 ]
```
- 신청 대기 중이면 모달 맨 위에 「50,000원 입금 확인 중 · 10:42 신청」 상태 줄, 같은 금액 중복 신청 막기.
- 카드 결제 결과 화면(성공/실패/닫힘)도 같은 톤의 카드 + 「지갑으로 돌아가기」.

# 추가 (2026-10-29 오후) — 계산서 연결 · 공동인증서 · 모바일/PC

## 전제: 청소비서 화면은 모바일과 PC 둘 다 1급
- 모든 화면은 **PC 1440px** 와 **모바일 390px(앱 WebView 포함)** 두 기준으로 설계·검증한다.
- PC: 입력 폼·모달 본문은 **최대 640px 폭**. 화면 전체 폭으로 늘어난 입력칸 금지. 카드 2열은 1024px 이상에서만.
- 모바일: 모달 = 아래에서 올라오는 **전체 화면 시트**, 하단 고정 주 버튼(엄지 위치), 표 = **카드 목록**으로 전환, 버튼 높이 44px 이상, 입력 시 키보드가 주 버튼을 가리지 않게(`mobile-keyboard-input-visibility.mdc`).

## 점검에서 나온 문제 (staging a4622d58, `/admin/team-leaders/cashbill`)
1. 이미 「가입완료」인데 업태·종목·전화·이메일 **빈 입력칸 + 회색 [연결하기]** 가 그대로 있어 아직 안 된 것처럼 보임.
2. **공동인증서 등록이 「▶ 세금계산서를 쓸 때만 필요」 접힌 칸 안에 숨어 있음**. 등록 상태·만료일 표시도 없음.
3. 현금영수증 가능 / 세금계산서 가능 여부를 한눈에 볼 곳이 없음.
4. 입력칸이 PC 전체 폭(약 650px × 2열)으로 늘어남.

## 4. 계산서 연결 화면 (`/admin/team-leaders/cashbill`)

브랜드마다 카드 1장. **상태에 따라 카드 내용이 바뀐다** (입력 폼은 미가입일 때만).

```
[계산서 연결]

┌ 바로빌 테스트  기본 브랜드 ───────────────────────────────┐
│ 주식회사 서비스브릿지 · 138-87-04035                         │
│                                                              │
│  현금영수증   ● 사용 가능                                    │
│  세금계산서   ● 공동인증서 필요            [공동인증서 등록]  │
│              (등록 후: ● 사용 가능 · 인증서 2027-03-14 만료) │
│                                                              │
│  업태 서비스 · 종목 청소 · 담당 010-****-1234 · a@b.com  [수정] │
└──────────────────────────────────────────────────────────────┘
```
- 미가입 상태: 같은 카드 안에 「연결 정보 입력」(업태·종목·전화·이메일, PC 2열 최대 640px / 모바일 1열) + 주 버튼 [바로빌 연결하기]. 입력이 다 차야 활성.
- 가입완료 상태: 입력칸 숨김, 위 요약 + [수정](모달).
- 검토 중 / 반려 / 연결 필요: 카드 상단에 상태 배너(회색/빨강/주황)와 사유, 해야 할 일 버튼 1개.
- 인증서 만료 30일 전: 세금계산서 줄을 주황 「곧 만료 · 2026-11-20」 + [다시 등록].
- 모바일: 카드 1열, [공동인증서 등록]은 줄 아래로 내려 전체 폭 버튼.

## 5. 공동인증서 등록 모달 (공용 컴포넌트, 두 곳에서 연다)

**여는 곳**: ① 계산서 연결 화면의 세금계산서 줄 ② **세금계산서 목록 화면** — 상단 주황 배너의 [공동인증서 등록] 버튼과, 목록 헤더 오른쪽 인증서 상태 칩(「인증서 미등록」/「인증서 ~2027-03-14」). 세금계산서 화면에서 바로 등록하는 것이 기본 동선.

```
공동인증서 등록                                               ✕
세금계산서를 발행하려면 사업자 공동인증서가 필요합니다. 1년에 한 번.

 ① 인증서 위치 선택 (PC·USB 등)
 ② 사업자 인증서 선택 (전자세금용 또는 사업자 범용)
 ③ 인증서 비밀번호 입력

[ 등록 창 열기 ]          ← 바로빌 자동로그인 URL. 항상 새 창(900×760). iframe 사용 안 함
 등록을 확인하는 중…  (5초마다 확인, 창 닫히면 1회 더)
 ✓ 등록 완료 · 만료일 2027-03-14     [세금계산서 발행하기]
```
- 모바일 접속: 모달 상단에 회색 안내 「공동인증서는 보통 PC에 있어요. PC에서 등록을 권장합니다」 + 그래도 진행 가능.
- 실패/시간초과: 「등록이 확인되지 않았어요 · 다시 확인 / 다시 열기」.
- 등록 완료 시: 세금계산서 화면 배너 사라지고 발행 버튼 활성(새로고침 없이).
